# 표시 기호 — 사용자에게 보여주는 응답의 이모지 어휘

> goax 의 skill·agent 가 사용자에게 보여주는 박스·보고·질문은 이 어휘만 써요.
> 상태 표시가 한눈에 들어오려면 **그림 이모지가 적어야** 해요 — 섹션마다 다른 그림이 붙으면 정작 ❌ 가 묻혀요.
> `tests/smoke.sh` 가 skills · agents · commands · docs/reference 에서 이 목록 밖 이모지를 막아요.

## 상태 (4)

| 기호 | 뜻 | 예 |
|---|---|---|
| ✅ | 통과 · 완료 · 보존됨 · 권장 옵션 | `✅ AGENTS.md (62줄)` · `●  [a]  자동 분류   ✅ 권장` |
| ❗ | 주의 · 확인 필요 · 위험 (drift · placeholder · 임박 · 단점) | `❗ tone.md placeholder` |
| ❌ | 실패 · 누락 · 비권장 | `❌ constitution — CLAUDE.md 가 없어요` |
| ⛔ | 막힘 · 되돌릴 수 없음 — 사용자 결정 전엔 진행하지 않아요 | `⛔ 이 명령은 추적 안 되는 파일을 지워요` |

정보성 문장엔 기호를 붙이지 않아요. 기호가 없는 줄이 "그냥 알아두면 되는 것" 이에요.

## 줄머리 표지 (4)

| 기호 | 뜻 |
|---|---|
| 📍 | 발견 · 지금 상태 (사실만, 추측 X) |
| 🎯 | 목표 · 이 질문이 정하려는 것 |
| 📂 | 영향 — 생성·수정될 파일 |
| 👉 | 다음 행동 |

## 룰 시그널 (3) — 룰 severity 전용

🔴 CRITICAL · 🟡 MANDATORY · 🔵 CONVENTION (`rules-tokens.md`). **상태 표시로 쓰지 않아요** — doctor 의 주의를 🟡 로
찍으면 "MANDATORY 룰" 과 구분이 안 돼요.

## 구조 글리프 — 이모지가 아니에요

`◆`(박스·섹션 제목) `│ ├ └ ─`(박스 선) `● ○`(권장 옵션 / 나머지) `▸`(입력 마커) `→ ↔ ·`(흐름·대응·구분).
섹션 제목은 `◆  <제목>` 이에요 — 그림 이모지를 붙이지 않아요.

## 쓰지 않는 것

- **VS16(U+FE0F) 이 붙는 이모지** — `⚠️` `ℹ️` `⚙️` 처럼 글자 기호에 이모지 표현을 덧씌운 것. 터미널마다 폭이 1칸·2칸으로
  갈려 박스 줄이 어긋나요. 경고는 ❗ 로 써요.
- **폭 1칸 글자 기호로 상태 표시** — `✓` `✗` `⚠` 는 작아서 안 보여요. 응답에선 ✅ ❌ ❗ 로.
  예외: HUD statusline(`spec ✓ › tasks ●`)과 스크립트 stderr 는 한 줄 폭이 중요해 글자 기호를 그대로 써요.
- **자축·장식 이모지** — 🥳 🎉 🚀 ✨ 🔥 등. `tone.md` 안티 패턴이에요. 완료는 `✅ … 완료` 한 줄이면 돼요.
