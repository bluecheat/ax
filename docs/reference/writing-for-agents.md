# 에이전트가 읽는 글 쓰기

이 문서는 모델이 읽고 그대로 행동하는 글의 기준이에요. 대상은 spirit 룰, 모듈 룰, SKILL.md, agents, 훅이 내보내는 문구,
스크립트의 `next_step` 이에요. 사람만 읽는 글(changelog, CONCEPTS)은 대상이 아니에요.

언어는 한국어, 말투는 `~해요` 체예요. 식별자, 경로, 명령, 정규식은 원문 그대로 써요.

## 왜 기준이 필요한가

- 모델은 맥락이 없는 새 동료처럼 읽어요. 쓴 사람이 아는 배경을 모델은 몰라요.
  ([Anthropic 프롬프트 가이드](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) — "a brilliant but new employee who lacks context")
- 한국어 자체의 성능 차이는 작아요 (영어 대비 Sonnet 96.7%, Haiku 93.3% —
  [다국어 성능표](https://platform.claude.com/docs/en/build-with-claude/multilingual-support)).
  차이를 키우는 쪽은 주어 생략과 맥락 의존이에요 ([KITE](https://arxiv.org/abs/2510.15558)).
- 이유가 붙은 지시는 모델이 예외 상황에도 맞게 적용해요. 이유가 없는 지시는 글자 그대로만 적용해요.

## 지시 한 개의 틀

```
<조건>에서, <주어>는 <행동>해요.
이유: <한 줄>
```

- **조건** — 언제 적용되는지. 항상이면 생략해요.
- **주어** — 이 세션, 리뷰어, lane-worker, 스크립트, 사용자 중 누가 하는지 적어요. 주어를 빼면 모델이 짐작해요.
- **행동** — 할 일을 적어요. 금지만 적으면 대신 무엇을 할지 모델이 정해요.
- **이유** — 한 줄. 사건 경위는 쓰지 않아요.

예시:

| 고치기 전 | 고친 뒤 |
|---|---|
| 구현 위임은 lane-worker 예요 — 다른 플러그인 훅 권고를 따라가면 규율이 통째로 빠져요 | 구현 단계에서 task 를 맡길 때, 이 세션은 `goax:lane-worker` 를 띄워요. 이유: 소유 파일 제한과 커밋 금지가 그 에이전트에만 있어요. |
| "delta 가 작으니 한 번만 더" 도 이 세션의 판단이 아니라 질문이에요 | 상한에 닿은 뒤 리뷰를 더 받을지는 사용자가 정해요. 이 세션은 바뀐 줄 수와 상관없이 사용자에게 물어요. |
| 진행 · 한 번 더 · spec 재정의 | 선택지는 셋이에요. (1) 지금 본문으로 진행 (2) 리뷰 한 번 더 (3) spec 다시 정의 |

## 쓰지 않는 것

| 쓰지 않는 것 | 대신 | 이유 |
|---|---|---|
| 날짜, 커밋 해시, PR 번호, "실측(…)", Phase·라운드·건수 같은 사건 경위 | changelog, mistakes, CONCEPTS 에 써요. 지시문에는 "이유:" 한 줄만 둬요 | 경위는 매번 읽히는 비용이고, 모델이 그 사건을 일반 규칙으로 오해해요 |
| ADR 본문 | `<!-- adr: <경로> -->` 링크 한 줄 | 결정의 근거는 ADR 이 원본이에요 |
| 비유와 구어 — "구멍", "통째로 빠져요", "먹혀요", "기울어요", "이겨요", "몫", "침묵" | "막지 못해요", "적용되지 않아요", "우선해요", "~가 맡아요", "출력이 없어요" | 비유는 해석이 갈려요 |
| `·` 로 셋 이상 나열 | 불릿이나 번호 목록 | 그리고인지, 또는인지, 순서인지가 사라져요 |
| `—` 로 이은 긴 문장 | 문장을 나눠요 | 조건과 행동과 이유가 한 줄에 섞여요 |
| "CRITICAL", "반드시!!", 대문자 강조 | 평범한 지시문 | 강한 표현은 과잉 반응을 불러요 |

## 파일별 메모

- **룰 (`## SP-…`)** — 제목은 규범 한 줄이에요. 본문은 8줄 이하예요. ✅/❌ 예시는 한 쌍이에요.
  검출 패턴 마커는 실제로 컴파일되는 ERE 로 써요. 한국어 설명 문장을 마커에 넣으면 아무것도 잡지 못해요.
- **SKILL.md · agents** — 본문에는 할 일과 순서만 둬요. 배경 설명이 필요하면 `references/` 로 옮겨요.
- **훅 · 스크립트 머리 주석** — 무엇을 하는지, 이유 한 줄, 입력·출력·Exit, 끄는 방법만 둬요. 사례는 hooks README 한 곳에 둬요.
- **훅이 모델에게 보내는 문구** — 첫 줄에 무엇이 막혔는지, 다음 줄에 할 일을 적어요. 할 일은 바로 실행할 수 있는 명령이나 동작이에요.

## 확인하는 방법

새 컨텍스트의 가장 약한 모델에게 그 글만 주고 상황 하나를 판정하게 해요. 판정이 의도와 다르면 글을 고쳐요.
사람에게도 같은 테스트가 통해요 — 맥락을 모르는 동료가 헷갈리면 모델도 헷갈려요.
