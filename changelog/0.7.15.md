# 0.7.15 — 룰을 한 가지 틀로 쓰고, 길어지면 줄여요

## 무엇이 좋아졌나 — 누구에게 체감되나

> 룰 파일을 직접 고치거나 mistake 를 룰로 올리는 사람, 그리고 편집할 때마다 룰을 읽는 모든 세션에 체감돼요.

- **"이거 룰로 만들어" 를 받는 skill 이 생겼어요 (`rule`).** 룰 하나를 고정 틀로 써요: 규범 한 줄 제목, 본문 1–3줄과
  `이유:` 한 줄, ❌/✅ 한 쌍, grep 으로 잡히면 검출 패턴. audit 이 고른 후보, onboarding 시드, 세션 안 요청이 모두 이 틀로 써져요.
- **룰에 날짜·PR 번호·세션 경위가 붙으면 바로 알려줘요.** 룰 파일을 고치면 post-edit 훅이 바뀐 블록만 검사해
  지적을 모델에게 돌려줘요. 막지는 않아요.
- **mistake 를 룰로 바꿀 때 기존 룰과 겹치는지 먼저 봐요.** 제목 낱말이 겹치는 룰이 있으면 새 ID 대신 기존 룰 보강을 물어요.
  grep 으로 못 잡는 룰은 새 컨텍스트의 작은 모델에게 룰과 상황 두 개만 주고, 판정이 의도대로 나오는지 확인해요.
- **룰이 길어지면 줄일 수 있어요 ("룰 압축").** 세션마다 실리는 양과 편집 한 번에 Read 하는 양을 재고, 글만 줄인 뒤
  SP ID · frontmatter · 검출 패턴 · 패턴 룰 예시 · ADR 링크가 그대로인지 스크립트가 확인해요.
  commerce 기준으로 상시 로드 394줄 · 19KB, 편집당 p90 34KB 를 재요.
- **skill · agent 문서의 비유와 사건 경위를 걷어냈어요.** 새 세션과 작은 모델이 읽는 글이라, 조건 → 주어와 행동 → `이유:` 한 줄로 고쳤어요.
