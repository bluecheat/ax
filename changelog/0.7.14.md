# 0.7.14 — 공통 함수를 기능별 파일로 나눴어요

## 무엇이 좋아졌나 — 누구에게 체감되나

> goax 에 기여하는 사람에게 체감돼요. 사용자 동작은 바뀌지 않아요.

- **`common.sh` 가 1,797줄에서 529줄로 줄었어요.** 기능별 함수는 `.ax/scripts/bash/lib/` 의 7개 파일로 옮겼어요.
  한 기능을 고칠 때 그 파일만 보면 돼요.
- **스크립트와 훅은 바뀌지 않았어요.** 지금처럼 `common.sh` 하나만 source 하면 모든 함수를 쓸 수 있어요.

## 바뀐 것

- `lib/secrets.sh` — 시크릿 패턴, redact
- `lib/shellscan.sh` — `goax_shell_scan`
- `lib/paths.sh` — 경로 정규화, yaml 목록, 글롭과 룰 매칭, 스택 파일, 작업 트리 지문, `commands.*` 읽기
- `lib/rules.sh` — 검출 패턴, 예시, frontmatter, 계약 테스트
- `lib/state.sh` — 작업별 상태 파일, 런타임 seed, 글롭 소유자
- `lib/lock.sh` — `goax_lock`, `goax_unlock`
- `lib/ids.sh` — spec/ADR ID, `--spec` 해석, tasks.md 파서
- `common.sh` — 출력, 세션 마커, 훅 프로필, 임시 파일, git 훅 경로, 프로젝트 루트, JSON 출력. 마지막에 `lib/` 를
  불러요. `lib/` 가 없으면 `/up` 을 안내하고 실패해요
- 쓰이지 않던 `goax_hook_report`, `goax_hook_exit` 를 지웠어요
- 설치는 그대로예요 — MANIFEST 의 `.ax/scripts/` 가 하위 디렉토리째 복사해요

  fixture 는 `$GOAX_LIB_SRC` 를 `common.sh` 와 같이 복사해요
