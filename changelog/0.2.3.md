# 0.2.3 — MEMORY.md 회상 인덱스 품질·토큰 개선

> `.ax/MEMORY.md`(triage 가 가장 먼저 읽는 빠른 회상 인덱스)를 외부 선례(llms.txt 의 index/detail, Aider repo map 의 personalization·토큰 예산)에 맞춰 다듬었어요. 룰 프리뷰가 원문 줄바꿈에서 잘리던 문제, 정적 최신순 덤프, silent 잘림을 고치고, 작은 프로젝트용 토큰 절약 모드를 추가했어요.

## 개선 — `build-memory.sh`

- **룰 프리뷰 첫 문장 join** — 시그널 라인 다음의 연속 설명 라인을 빈 줄/`- ` 메타 전까지 이어붙여요. 예전엔 첫 물리 라인만 잡아 `모듈 의존 방향 단방향:` 처럼 wrap 지점에서 끊겨 핵심 제약(의존 DAG·역방향 금지)이 통째로 빠졌어요. 이제 마지막 공백/마침표 경계에서 끊고 `…` 표기.
- **현재 작업 personalization (★)** — `current-task.json` 의 `domain` 토큰에 걸리는 ADR/spec/모듈을 `★` 로 끌어올려요(Aider repo map 의 "현재 컨텍스트로 편향" 을 cheap substring 으로 근사). 정적 최신순 덤프가 놓치던 관련 항목이 위로 와요.
- **섹션 예산 + 명시적 생략** — 임의 `tail -10` 대신 섹션 예산(8) + 초과분 `… +N more → <dir>` 한 줄. 헤더 총계와 reconcile (silent 잘림 제거).
- **토큰 모드** — `--no-preview`(룰 토큰+경로만), 크기 게이트(`--lean`/`--full`/auto). 인덱스가 가리킬 본문 합계 < `GOAX_MEMORY_LEAN_BYTES`(기본 12000)면 자동 lean — 모듈/ADR/spec/mistakes 를 `(N) → <dir>` 로 접어 작은/greenfield 프로젝트의 인덱스 오버헤드를 없애요(현재작업·룰은 유지). 헤더에 모드+이유를 노출하고 `--json` 에 `mode`/`body_bytes` 추가.

## 수정 — `build-memory.sh`

- **Constitution SSOT 선택 버그** — 0.2.0 의 AGENTS.md SSOT 전환 이후 CLAUDE.md 는 `@AGENTS.md` alias(시그널 0줄)인데, `RULES_FILE` 가 여전히 CLAUDE.md 를 먼저 집어 **룰이 0개로 보이던** 회귀를 수정. "먼저 존재하는 파일" 이 아니라 "실제 🔴/🟡 시그널을 가진 파일" 을 선택.
