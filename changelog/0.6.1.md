# 0.6.1 — 진단이 인프라 실패를 초록불로 찍던 것 (mktemp · git 폴백) + 결정론 층까지 닿는 eval

> `claude plugin eval` 을 goax 의 hook·스크립트가 실제로 도는 자리까지 내리자, 샌드박스가 스크립트 두 구멍을
> 드러냈어요. `$TMPDIR` 쓰기가 막히면 `check-rule-enforcement.sh` 가 룰을 하나도 안 읽고 "all invariants pass" 를
> 찍었고, `/usr/bin/git` 이 못 돌면 `check-sensor-liveness.sh` C2 가 "pre-commit 미설치" 로 오탐했어요. 진단 도구가
> 자기 인프라 실패를 통과로 보고하던 자리예요. 같은 판에서 I6 의 출고 훅 제외 목록 누락도 잡혔어요 — git 저장소에
> 설치한 모든 프로젝트에서 external 룰의 I6 가 영원히 통과하고 있었어요.

## 무엇이 바뀌었나

- **`common.sh`** — `goax_mktemp [-d] [root]`: `mktemp` → `.ax/.session/tmp/` 폴백 → umask 077 순수 bash, 전부
  실패하면 1 을 돌려주고 사유는 stderr 에. 호출자는 `|| { goax_tmp_error; exit "$EXIT_ERROR"; }` 로 받아요 (헬퍼 안에서
  exit 하면 `$(...)` 서브셸만 끝나요). `goax_git_hook_path <root> <hook>`: `git rev-parse --git-path` 가 죽으면
  `.git`(디렉토리 · `gitdir:` 포인터 · linked worktree 의 `commondir`)과 `.git/config` 의 `core.hooksPath`(따옴표·주석
  제거 · `[core]` 대소문자 무시)를 직접 읽어 절대경로를 내요.
- **mktemp 를 쓰던 자리 전부 헬퍼로** — `check-rule-enforcement.sh` · `check-spec-clarity.sh`(`--file` 모드 포함) ·
  `promote-mistake.sh` · `zero-probe.sh` · `zero-verify.sh`(두 zero 스크립트는 로그 디렉토리를 trap 으로 지워요), 그리고
  **`scripts/provision.sh`** 2곳 — 백업 디렉토리 mktemp 가 죽으면 백업이 `/` 에 떨어지고 MANIFEST 복사가 사용자 수정
  템플릿을 덮어쓰던 자리, `AGENTS.md` 비교용 임시 파일이 비면 매번 "사용자 수정" 으로 오보하던 자리예요. 이제 둘 다
  `die` 로 멈춰요. `templates/zero/probe/examples/*.sh` 는 독립 스크립트라 `|| exit 1` 가드만.
- **`check-rule-enforcement.sh` I6** — 출고 훅 제외 목록에 `spec-completion-gate.sh` 추가. 빠져 있던 동안 갓 설치한
  프로젝트에서 그 훅이 "프로젝트 전용 훅" 으로 세어져 `external:*` 룰이 늘 트리거 있음으로 통과했어요.
- **`check-sensor-liveness.sh` C2 · `check-rule-enforcement.sh` I6** — git 훅 경로를 `goax_git_hook_path` 로.
- **evals** — 샌드박스는 프로젝트 `.claude/settings.json` 을 안 읽어요. `tests/eval-hook-shim/` 이
  `settings.json.template` 의 hook 등록을 플러그인 hook 으로 미러하고, 세 케이스가 전부 `scaffold.sh`(`provision.sh` 로
  실제 설치 + 픽스처)로 바뀌었어요 — `critical-canary`(SP-SEC-001 이 파일에만 있을 때 `spirit-rules-inject.sh` 가 닿게
  하는가), `doctor-i6`(doctor 가 자기 스크립트로 I6 를 내는가), `triage-first`(`triage-nudge.sh` 가 구현 의도를 감지하고
  triage 가 먼저 오는가). 실행 명령은 `--scaffold --allow-tools Bash Write Edit --judge-model sonnet`.
