# 0.1.11 — audit 3단계 강제 + mistake archive

## 1) Audit 3단계 강제 — 마킹 → 룰 본문 → archive

`audit` skill 이 `--apply` (마킹) 만 하고 종료하던 버그 수정. `promote-mistake.sh` next_step 이 advisory 톤 + skill §4 가 두 단계만 안내해서 LLM 이 조기 종료하던 문제.

- `promote-mistake.sh --apply` next_step → `"MANDATORY 2 steps remain: (1) Edit .ax/spirit/rules/<project>-<cat>.md add <token> ... (2) bash promote-mistake.sh --archive --token <token>. Skill must NOT report success until both done"` 강제
- `audit SKILL §4` — 두 단계 → 3단계 (4.1 마킹, 4.2 룰 본문 + 완료 검증, 4.3 archive + 완료 검증)
- `audit SKILL §6 (절대 금지)` — 마킹만 하고 룰 본문/archive 스킵 후 보고 X

## 2) `promote-mistake.sh --archive` 신규 — 처리 완료 mistake 자동 격리

```bash
bash .ax/scripts/bash/promote-mistake.sh --archive --token SP-SEC-001 [--json]
```

- 사전 검증 — SP 토큰이 `.ax/spirit/rules/*.md` 에 `## <token>` 헤딩으로 존재해야만 진행 (없으면 `SP token not found` 에러)
- `promoted_to: <token>` 마킹된 mistake 들을 `.ax/mistakes/_archive/<YYYY>/<MM>/` 로 mv
- 모든 scan path (`promote-mistake.sh`, `update-state.sh`) 이 이미 `find -maxdepth 1` → archive 된 파일은 audit candidate / count / HUD 에서 자동 제외
