# 0.2.2 — triage-search 공백 키워드 크래시 수정

> 0.2.1 의 edge-case 패치. 공백-only 키워드 + `search-aliases.yml` 설치 상태에서 `triage-search.sh` 가 빈 출력·exit 1 로 죽던 문제를 수정.

## 수정

- **`triage-search.sh` `expand_keywords`** — 전부-공백 키워드의 동의어 확장 마지막 파이프라인(`... | grep -v '^$' | awk | tr`)이 매칭 0줄로 `grep` exit 1 → `set -euo pipefail` + 명령치환 할당이 abort → **빈 stdout·exit 1** (triage SKILL 의 JSON 핸드오프 깨짐). 파이프라인에 `|| true` 가드 추가 — 빈 결과는 기존 `ALT` 빈값 경로로 흘러 깔끔한 `json_error("keywords resolved to empty pattern")` 로 처리돼요.
- `search-aliases.yml` 미설치 환경에선 `expand_keywords` 가 조기 return 해서 재현 안 됨. **실제 설치엔 alias 파일이 항상 있어** 이 경로를 타므로, 유닛 fixture 가 아니라 설치 상태 그대로의 E2E 시뮬레이션으로 검출했어요.

## 검증

- bash 3.2.57(macOS 기본) + 5.x / `tests/smoke.sh` 전체 통과
- E2E 시뮬레이션(plugin install → MEMORY.md → triage-search 한+영 → 엣지 → 대형 >120 → staleness) **34/34 통과**
