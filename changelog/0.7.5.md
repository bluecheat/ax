# 0.7.5 — 인계 노트에 spec ID 만 적어도 Stop 게이트가 알아봐요

## 무엇이 좋아졌나 — 누구에게 체감되나

- **spec ID 로 적은 인계 노트를 인정해요.** Stop 게이트(`stop/spec-gate.sh`)는 인계 노트의 '지금 상태' 에서 spec
  디렉터리의 **전체 이름**(`2026-10-03-1b92-sharing-movement-web-mvp`)만 찾았어요. 다른 스크립트의 `--spec` 은
  `2026-10-03-1b92` 같은 ID 로 찾는데요. 한 실사용 프로젝트에서 `status-note.sh --set now "spec 2026-10-03-1b92
  implementing — …"` 으로 적었는데 게이트가 "인계 노트에 적혀 있지 않다" 며 한 번 더 막았고, 전체 이름으로 다시
  적어야 통과했어요. 이제 ID(`YYYY-MM-DD-<4hex>`, 옛 순번 `NNN`)든 전체 이름이든 통과해요.
- **안내 문구가 ID 로 적는 법을 보여줘요.** 게이트가 멈춰 세울 때 내놓는 `status-note.sh --set now` 예시가 spec ID 를
  쓰고, ID 나 전체 이름이 있으면 다시 잡지 않는다고 알려요.

## 바뀐 것

- `stop/spec-gate.sh`: spec ID 는 `common.sh` 의 `goax_doc_key` 로 뽑아요 (형식 판별 SSOT). ID 는 앞뒤가 ASCII 영숫자가
  아닐 때만 인정해요 — 옛 순번 `014` 가 `T0140`·`2014` 에 걸리지 않고, `1b92에서` 처럼 한글이 바로 붙어도 알아봐요.
  전체 이름 부분 일치는 예전 그대로예요. 24시간(`now_at`) 조건도 그대로예요.
- `hooks/README.md` Stop 게이트 절.

## 검증

- smoke 738 통과 (macOS bash 3.2). Stop 게이트 5건 추가: 옛 순번 ID · 경계(`T0140`·`2014` 불인정) · 안내 문구의 ID 예시 ·
  새 ID/한글 붙은 ID/전체 이름 · 다른 spec 의 ID 불인정.
