# 0.2.1 — triage 검색 연관성·토큰 효율 개선 + MEMORY.md·BM25 인덱스

> triage 사전 검색을 키워드 boolean grep(랭킹·스니펫 없음, 경로만 반환)에서 **연관성 랭킹 + 스니펫 반환 + 동의어 확장 + 도메인 boost** 로 개선했어요. bash+markdown 헌법과 결정론 경계 안, 무의존(jq+POSIX). 소형 프로젝트는 기존 grep 경로 그대로(회귀 0).

## `triage-search.sh` 개선

- **매칭 줄수 랭킹**(`grep -cE`) + 상위 K + **스니펫**(`grep -nE`) 반환 → LLM 이 통째 read 전에 연관성을 판단(토큰 절감). 결과 스키마가 경로 배열 → object 배열로:
  ```json
  { "path": "...", "score": 4, "snippets": ["12: ..."], "boosted": false, "match": "refund" }
  ```
- **동의어 확장**(`.ax/search-aliases.yml`) — 키워드를 같은 그룹으로 OR 확장. `refund` 검색이 `환불`·`reimbursement` 본문도 매칭(paraphrase recall 보강). 키워드-only grep 의 한글 누락을 메우는 결정론 레이어.
- **ripgrep-if-present**(grep fallback) — rg 있으면 본문 후보 listing 가속. **rg 유무와 결과 동일**(점수·스니펫은 grep 으로 재채점 → 결정론 유지).
- **도메인 recency boost**(`.ax/current-task.json` 의 `domain`) — 현재 작업 도메인 자료를 상위로. `boosted` 플래그로 노출, raw `score` 는 보존(boost 는 정렬키에만).
- **tiered (대형 코퍼스)** — 코퍼스 >120 파일 시 BM25 역색인으로 후보를 **union**. recall 절대 손실 없음(grep 결과 ⊆ 결과), 소형 프로젝트는 grep 경로 그대로(**회귀 0**).

## 신규 스크립트

### `templates/default/.ax/scripts/bash/build-memory.sh`

`.ax/` 상태 → `.ax/MEMORY.md` **한 줄 포인터 인덱스** 재생성. 현재 작업·🔴/🟡 룰·모듈·최근 ADR·열린 mistakes·spec 을 본문 없이 *포인터만* 담아 작게 유지. triage 가 검색 전 **가장 먼저 read** (index/detail 분리 — 토큰 싸게 현황 파악, 관련 항목만 본문 read).

### `templates/default/.ax/scripts/bash/build-index.sh`

`.ax/.search-index` **역색인**(탭 구분 평문, git-diff 가능) 빌드 + `--query` BM25 랭킹 + staleness 감지(mtime + 코퍼스 수 변동으로 추가·수정·**삭제** 감지). ASCII 토큰 기반(한글은 grep 경로 담당). 대형 코퍼스 tier 의 후보 탐색용 **재생성 캐시**.

### `templates/default/.ax/search-aliases.yml`

동의어 시드(사용자 커스터마이즈). `up` 재설치 시 `.suggested` 로 보존(config.yml 패턴).
