# 0.1.3 — state.json 버전 stamp + hook chain safety + 보안 hardening

> 동작 변경 없는 버그 픽스 + 가드 보강.

## RED — 즉시 수정

### 1) `state.json.template` hardcoded `goax_version: "0.1.0"`

모든 사용자가 plugin 버전과 무관하게 `goax_version: 0.1.0` stamp 받던 버그. HUD·doctor·diagnostics 항상 0.1.0 이라고 보고.

수정:
- `templates/default/.ax/hud/state.json.template`: `"goax_version": null` 로 placeholder
- `templates/default/.ax/scripts/bash/update-state.sh`: `.ax/version` 파일에서 `goax:` 라인 파싱해 매 실행 시 jq 로 patch. `.ax/version` 없으면 null 유지

검증: `.ax/version=0.1.3` → `state.json.goax_version=0.1.3`

### 2) `grep-on-commit.sh` 의 `set -e` + `bash $hook` chain killer

`set -euo pipefail` 상태에서 chained hook 이 exit 1 (warning) 리턴하면 set -e 가 trap → 후속 hook 모두 silent skip.

수정:
- `set -euo pipefail` → `set -uo pipefail` (-e 제거, chain 의 exit code 직접 처리)
- `bash "$hook"` → `bash "$hook" || RC=$?` (실패해도 RC 잡고 계속)
- 단일 파일 위임을 `pre-commit/*.sh` 자동 chain 으로 default 승격 — onboarding 이 deployed 에서 이 파일 직접 rewrite 할 일 없도록

검증:
- warning hook (exit 1) 만나도 chain 끝까지 진행 ✓
- fail hook (exit 2) 만나면 즉시 차단 + EXIT=2 propagation ✓

### 3) `xargs -I{} sh -c '...{}...'` 명령 주입 가능성

secrets 검출 라인이 파일명에 백틱·`"`·`$` 들어가면 sh -c 파싱이 깨져 syntax error 또는 임의 명령 실행 가능. pre-commit hook 이 untrusted input (staged 파일)에 돌아가는 구조라 보안 hardening.

수정 (`templates/default/.ax/hooks/pre-commit/critical-rule-grep.sh`):
- `xargs -I{} sh -c '...'` → `while IFS= read -r f; do ...` 안전 loop
- 검증: 일반 파일명·특수문자 파일명 모두 처리, password 패턴 정상 검출
