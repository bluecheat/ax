# 0.7.18 — audit 을 마쳐도 "마지막 audit" 이 그대로라 세션 브리핑이 계속 주기 초과를 알리던 것

## 무엇이 좋아졌나 — 누구에게 체감되나

> audit 으로 mistake 를 회고하는 모든 설치본에 체감돼요.

- **audit 을 마치면 마지막 audit 시각이 바뀌어요.** `last_audit` · `due_in_days` 는 `.ax/mistakes/.last-audit` 에서 계산하는데,
  이 파일을 쓰는 곳이 없었어요. audit skill 대로 `update-state.sh --skill audit` 을 돌려도 값이 그대로라, 세션 브리핑이
  "마지막 audit N일 전" 을 계속 띄웠어요. 이제 `--skill audit` 이 그 파일을 지금 시각으로 써요.
- **rule skill 마무리가 state.json 에 기록돼요.** §9 가 `update-state.sh --skill rule --json` 을 안내했는데, `--json` 은
  출력만 하고 파일을 쓰지 않아 `last_skill` 이 안 찍혔어요. `--json` 을 뺐어요.

## 바뀐 것

- `update-state.sh --skill audit` — `.ax/mistakes/.last-audit` 에 epoch 를 쓴 뒤 `last_audit` · `due_in_days` 를 계산해요 (`--json` · `--dry-run` 은 안 써요)
- `audit` skill — state.json 갱신 절이 실제 동작(`.last-audit` 기록, `--json` 금지)을 적어요
- `rule` skill §9 — `--json` 제거
- smoke §12 — `--skill audit` 기록과 `--json --skill audit` 불변 검사

## 올릴 때

- `.ax/mistakes/.last-audit` 는 mistake 기록과 함께 공유되는 값이에요. `.ax/mistakes/` 를 커밋하는 팀은 이 파일도 같이 커밋해요.
