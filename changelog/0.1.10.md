# 0.1.10 — mistake skill 본문 작성 강제 + template 청소

## 1) Mistake skill 본문 작성 강제

`init-mistake-file.sh` 호출 후 LLM 이 5섹션 (어디서 / 왜 발생 5 Whys / 어떻게 막을 수 있나 / 영향 Cost / audit 액션) 을 Edit 으로 채우도록 강제.

- `init-mistake-file.sh` next_step → `"MANDATORY next: Edit ..."` + 5섹션 + placeholder 마커 enumeration (`파일/모듈/도메인.`, `1. 왜 X? → A`, `<예:` 등) + "보고 직전까지 잔재 0"
- `skills/mistake/SKILL.md §3` — 5섹션 표에 교체 대상 placeholder 컬럼 + "완료 검증 (보고 직전 필수)" 블록 (Grep 으로 마커 잔재 0 검증, 잔재 1건이라도 있으면 추가 Edit + "캡처 완료" 보고 금지)
- `SKILL.md §6 (절대 금지)` — placeholder 항목 검증 필수로 강화

## 2) `## 이력` 라인 날짜 추가

`init-mistake-file.sh` 의 `최초 캡처` / `재발` printf format `+%H:%M:%S` → `+%Y-%m-%d %H:%M:%S`.

- 최초 캡처: `- 최초 캡처 2026-05-06 16:44:40`
- 재발: `- 재발 2026-05-06 16:44:40 — <details>`

## 3) Template 청소

`_templates/mistakes/mistake.md` 에서 두 라인 삭제 — script append 가 단일 SSOT:

- 상단 HTML 주석 (`<!-- enum 가이드 -->`): `skills/mistake/SKILL.md:37-39` 가 SSOT, 중복 + cp 시 생성 파일 헤더 오염
- `## 이력` 섹션의 `- 최초 작성 <HH:MM:SS>` placeholder: 미치환 대상이라 `init-mistake-file.sh` append 와 겹쳤음
