## 시크릿 패턴 SSOT

검출(`critical-rule-grep.sh` 의 인라인 상수)과 마스킹(`common.sh` 의 `redact_secrets` sed)이 따로 살아서 8축이 갈라져
있었어요 — AWS·GitHub·Stripe·PEM·JWT 정량자, Slack 웹훅은 마스킹만, key=value 는 값 길이는 물론 **키 이름까지**
(검출에만 `passwd`·`access_key`, 마스킹에만 `pg_key`).

- `common.sh` 에 `goax_secret_rules` — 4열 탭 표 하나(인용 heredoc). `goax_secret_patterns`(검출, `grep -E -e`)와
  `redact_secrets`(마스킹, sed 스크립트 도출)가 거기서 나와요. key=value 두 행은 키 목록 조각을 공유해요.
- 갈라진 축은 넓은 쪽으로 통일 — AKIA `{16,}`, `gh[hoprsu]_`, Stripe `{16,}`, PEM 수식어 선택, JWT 3세그 선택,
  Slack 웹훅 검출 승격. 실검체 16/16 검출, 오탐 0/4.
- 훅은 패턴을 자체 보유하지 않아요. `common.sh` 가 없으면 `critical-rule-grep.sh` 도 `check-mistake-secrets.sh` 도
  조용히 통과하지 않고 stderr 에 "secrets 안전망 비활성" 을 말하고 통과해요.

## 파일 쓰기 락 — 대상 파일 6개

`common.sh` 의 `goax_lock` 을 만들어 놓고 원장과 봉인에만 쓰고 있었어요. `tmp.$$ && mv` 를 쓰는 나머지 여섯이 이제
락을 잡아요 — `status-note.sh`(STATUS.md) · `register-spirit-hook.sh`·`zero-init.sh`(settings.json, 같은 락 문자열) ·
`build-memory.sh`(MEMORY.md) · `constitution-apply.sh`(세 모드 전부) · `zero-domain-risk.sh`(config.yml).

- 락 창은 `mv` 직전이 아니라 **"바꿀지 말지를 정하는 첫 읽기"** 부터예요 — 멱등 `grep -q`·`ensure_file`·`scan_dups`
  가 락 밖이면 두 세션이 둘 다 "없음" 을 읽고 둘 다 써요. 동시 실행 회귀: 수정 전 14/10 → 24/0
  (`zero-init ×5` 등록 3회→1회, `status-note --add` 동시 10회 유실 10/10→0).
- dry-run 은 락도 파일도 안 만들어요 — `status-note` 의 `ensure_file` 이 dry-run 앞에서 STATUS.md 를 만들던 것 정정.
- 타임아웃은 호출부 인자(`GOAX_LOCK_TIMEOUT`, 기본 10초). 실패는 exit 1 + `{"status":"error"}`.
- stale 회수는 **살아 있는 홀더를 절대 안 뺏어요** — 죽은 pid(5초 뒤)와 pid 파일 없는 락(`GOAX_LOCK_STALE`)만.
  예전엔 디렉토리 mtime 60초로 무조건 회수해서 정당한 홀더를 뺏을 수 있었어요.
- `.gitignore.template` 에 `*.lock/` — 슬래시가 있어야 사용자 프로젝트의 `Cargo.lock`·`Gemfile.lock` 을 안 삼켜요.
- `zero-init.sh` 의 템플릿 복사가 동시 실행에서 리눅스 GNU cp 의 `File exists` 로 죽던 것 — 목적지가 이미 있으면 설치된 것으로.

## `zero-verify.sh` 주석 파서

`commands.typecheck: 'grep -c "#" README.md'` 를 읽다가 따옴표 안 `#` 에서 잘라 `grep -c "` 를 돌리고 "실패" 로
보고했어요. YAML 규칙 그대로 sed `t` 분기로 — 값이 따옴표로 시작하면 짝 닫는 따옴표까지가 값, `#` 으로 시작하면
값 전체가 주석(빈 값 = 안 돌림, PASSED 로 승격되지 않아요), 그 외엔 **공백 뒤** 첫 `#` 앞까지. `it's fine  # 주석` 의
아포스트로피, `--grep=#123`·URL `#frag` 도 안 다쳐요. 회귀 13종. 의도된 축소 하나: `"say \"hi\""` 는 `say \` 예요.

## smoke — warning 모드 회귀

`assert_blocked`/`assert_passed` 는 exit code 만 봐서 `block-destructive.sh` 의 warning 갈래(exit 0 + stderr 경고)가
통째로 사라져도 초록이었어요. `assert_warned`(exit 0 **이면서** stderr `[goax hook]`) 를 두고 git push 4종·
`git reset --hard`·`git clean -xfd`·`sudo rm` 을 옮겼고, `assert_passed` 는 stderr 무음까지 요구해요. §15/§41 분담을
명시하고 경계 어서션은 섹션 마커 앵커(행 번호 아님). §41 시크릿 6 · §42 파서 14 · §43 락 동시성 14 신설.

## 리눅스 이식성 — 이 판에서 같이 잡힌 것

- 브래킷 안 멀티바이트 문자(`[—–-]`·`[-•·]`·`[🔴🟡🔵]`)를 교대(`|`)로 — POSIX 로케일 GNU sed 가 바이트 집합으로 읽어
  첫 바이트만 지우고, ubuntu 컨테이너에서 `constitution-apply` 중복 스캔이 0.5.6 부터 빨갛던 원인이에요.
- `stat -f %m || stat -c %Y` 순서 — GNU `stat -f` 는 파일시스템 모드라 실패해도 stdout 에 글자를 찍어 뒤 fallback 과
  섞여요. 리눅스에서 락 stale 회수와 세션 TTL 청소(`goax_inject_fresh`·`triage-nudge`)가 조용히 안 돌고 있었어요.
  GNU 형식을 먼저 + 숫자 검증.
