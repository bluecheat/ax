# 0.4.0 — 공개 준비: 훅 우회 차단 + 집행 강도의 정직한 문서화

> 외부 공개 전 보안 검토에서 나온 발견을 반영해요. 핵심은 하나예요 — **차단 훅이
> "차단한다고 적힌 것"과 "실제로 차단하는 것"이 어긋나 있었어요.** 0.3.1 이 *라벨과
> 집행 트리거의 일치*를 밀어붙였다면, 0.4.0 은 그 다음 층 — *집행 코드가 실제로
> 집행하는지*, 그리고 *집행이 무엇을 보장하고 무엇은 보장하지 않는지*를 맞춰요.

## 변경 — `block-destructive.sh` 재작성 (차단 실효성 역전 수정)

기존 CATASTROPHIC 패턴은 **OS 가 이미 막는 형태만 잡고, 실제로 통하는 형태는
전부 통과**시켰어요. `rm -rf /` 는 `rm` 자체가 `--preserve-root` 로 거부하는데
(`rm: "/" may not be removed`), 정작 시스템을 파괴하는 `rm -rf /*` 는 패턴이
`/` 뒤에 공백·EOL 을 요구해서 빠져나갔어요.

실측으로 확인된 우회 (전부 수정 + smoke 에 고정):

| 명령 | 이전 | 지금 |
|---|---|---|
| `rm -rf /*` (루트 글롭) | 통과 | 차단 |
| `rm -rf "/"` (따옴표) | 통과 | 차단 |
| `rm -rf /usr /etc` | 통과 | 차단 |
| `rm --recursive --force /` | 통과 | 차단 |
| `rm -rf ~` · `$HOME` | 경고만 | 차단 |
| `find / -delete` · `-exec rm` | 통과 | 차단 |
| `chmod -R 777 /` · `chown -R … /` | 부분 | 차단 |

- **정규화 단계 추가** — 따옴표 제거 + 공백 정리로 표기 변형(`"/"`, 탭 구분)을 흡수해요.
- **판정 구조 변경** — 단일 정규식 나열에서 `rm 호출 × 재귀 플래그 × 위험 대상 경로`
  3조건 교차로 바꿨어요. long option(`--recursive`)도 잡히고, false positive 도 줄었어요.
- **오탐 방지를 테스트로 고정** — `rm -rf node_modules`, `rm -rf /tmp/…`, `git rm -r --cached`,
  `find . -delete`, `grep -r /` 는 반드시 통과해야 해요.

## 변경 — `check-protected-paths.sh` 경로 정규화 + 경계 매칭

- **표기 변형 우회 차단** — `./CLAUDE.md`, `<root>/./CLAUDE.md`, `<root>/.ax/../CLAUDE.md`,
  중복 슬래시가 전부 보호를 우회했어요. 이제 렉시컬 정규화 후 판정해요.
- **경계 검사** — 접두 매칭이라 `CLAUDE.md` 패턴이 `CLAUDE.md.bak` 을 오탐했어요.
  경로 경계(`/`)를 지키는 `goax_path_under` 로 교체.
- **조용한 무력화 제거** — `protected_paths` 를 `awk` range 로 뽑았는데, 시작 라인이
  종료 패턴에도 매칭되면 range 가 1줄로 붕괴해서 **경고 없이 빈 목록**이 됐어요.
  (`protected_paths:` 가 최상위에 있는 YAML 이면 훅이 통째로 no-op). 들여쓰기 인식
  파서로 교체하고, 키는 있는데 항목을 못 읽으면 **경고를 출력**해요 — 보안 컨트롤이
  소리 없이 꺼지는 건 없는 것보다 나빠요.
- 같은 정규화를 `spirit-check.sh` · `spirit-rules-inject.sh` 에도 적용했어요.

## 추가 — `common.sh` 공용 헬퍼 3종

경로 판정을 각 훅이 문자열 절단으로 따로 하던 걸 한곳으로 모았어요. bash 3.2(macOS 기본) 호환.

- `goax_normalize_path <path> [base]` — `.`·`..`·중복 슬래시 해소 후 절대경로.
  `realpath` 비의존이라 아직 없는 파일도 처리돼요 (Write 는 새 파일을 만듦).
- `goax_path_under <rel> <pattern>` — 경로 경계를 지키는 포함 판정.
- `goax_yaml_list <file> <key>` — 들여쓰기 인식 YAML 시퀀스 추출. 블록·flow 형식 모두.

## 변경 — 집행 강도를 정직하게 문서화

이전 문서는 🔴 CRITICAL 을 "자동 차단, **우회 불가**" 로 적었어요. 훅이 bash 패턴
매칭인 이상 이건 지킬 수 없는 약속이에요. `rule-enforcement.md` 가 "hook 없는 🔴 은
거짓 약속" 을 막아왔는데, 반대 방향의 거짓 약속 — *"hook 이 있으니 안전하다"* — 은
막지 않고 있었어요.

- `docs/reference/rule-enforcement.md`: **"집행 강도의 한계"** 절 신설. 훅이 잡는 것
  (의도치 않은 실수)과 못 잡는 것(우회 의도, 훅이 안 보는 도구 경로, `--no-verify`)을
  표로 명시. 🔴 의 의미를 "우회 불가" → **"사고로는 통과 못 함"** 으로 정정.
- `README.md` · `README.ko.md`: **"보안 모델"** 절 신설. 위 내용 + `.ax/` 가 저장소를
  따라다니는 실행 가능한 코드라는 점(외부 저장소를 열 때의 신뢰 모델)을 설명해요.

## 변경 — 기타

- `triage-search.sh`: 키워드 확장 루프를 `set -f` 로 감쌌어요. 미인용 확장이라
  키워드에 `*` 가 들어오면 cwd 파일명으로 glob 확장돼 검색이 깨졌어요.
- `tests/smoke.sh`: MANIFEST orphan 스캔이 `.omc/`·`.git/`·`node_modules/` 같은
  런타임 산출물을 건너뛰어요. 도구가 `templates/` 안에 파일을 흘리면 무관한 실패가 났어요.
- `promote-mistake.sh`: `${#CANDIDATES[@]:-0}` 수정. bash 3.2(macOS 기본) 는 이 문법을
  조용히 `0` 으로 받아주고 bash 5.x(CI ubuntu) 는 `bad substitution` 으로 죽어요 —
  macOS 로컬에선 영영 안 보이는 종류의 버그라 smoke 에 §19 bash 호환 lint 를 함께 넣었어요.
  검증도 Ubuntu 24.04 / bash 5.2 컨테이너에서 전체 스위트를 돌려서 확인했어요.
- `.gitignore`: `.claude/settings.local.json` 추가. 사용자 전역 gitignore 에만
  의존하면 다른 기여자·CI 환경에서 새어나가요.
- 히어로 이미지 교체 — 단순 2D 마스코트(하네스 착용)로. 벡터 소스(`goax_img.svg`)를
  함께 두고, PNG 는 7.0MB → 0.6MB.

## 마이그레이션

기존 사용자는 `/plugin marketplace update goax` → `/plugin install goax` 후
프로젝트에서 `up` 을 다시 돌리면 훅이 갱신돼요.

**동작이 달라지는 지점** — 이전에 통과하던 명령 일부가 이제 차단돼요
(`rm -rf ~`, `rm -rf /*` 등). 의도된 변경이에요. 반대로 `protected_paths` 가 최상위
YAML 이라 조용히 꺼져 있던 프로젝트는 이제 실제로 차단이 걸리기 시작해요 — `doctor`
로 상태를 먼저 확인하시길 권해요.
