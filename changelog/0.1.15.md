# 0.1.15 — spec/README 출고 제거 (Layer 3 책임 분리)

## 핵심 변경

`templates/default/.ax/docs/spec/README.md` 출고 제거. `.keep` 으로 대체 (adr 디렉토리와 동일 패턴).

## Why

`.ax/docs/spec/` 는 **사용자 결정 산출물 공간** (Layer 3 — Spec/ADR). 그런데 plugin 이 거기에 *튜토리얼/사용법 README* 를 박아 넣어 다음 문제 발생:

1. **내용이 outdated** — 이전 버전 디렉토리 구조(`.ax/docs/spec/_templates/`, 실제는 `.ax/_templates/spec/`) + 존재하지 않는 skill 이름(`spec-new`, 실제는 `spec`) 인용
2. **Layer 책임 침범** — plugin 이 user 프로젝트에 가이드 문서를 새겨놓으면 사용자가 자기 spec 인덱스 README 를 만들 자리가 없음
3. **Drift 잡음** — 사용자가 README 수정하면 doctor 가 매번 "user-modified" 로 잡음
4. **튜토리얼 위치 잘못** — "사용법" 은 plugin 의 skill description / `docs/reference/` 에 있어야지 user 프로젝트로 새지 말아야 함

## What

- 삭제: `templates/default/.ax/docs/spec/README.md`
- 추가: `templates/default/.ax/docs/spec/.keep` (빈 placeholder, 디렉토리 보존용)

## 마이그레이션

기존 사용자 (0.1.14 이하 설치) 의 `.ax/docs/spec/README.md` 는 *그대로 유지* (자동 삭제 X). doctor 가 더 이상 backfill 하지 않음. 사용자가 직접 정리 원하면 `rm .ax/docs/spec/README.md` 또는 자기 인덱스로 교체.

## 후속

- `docs/reference/spec-workflow.md` 같은 plugin-측 reference 신설은 보류 — 현재 `skills/spec/SKILL.md` + `docs/reference/triage-matrix.md` + `docs/reference/confirmation-policy.md` 로 가이드 충분히 커버됨.

## 검증

`tests/smoke.sh` 통과 (구조 변경 없음, 파일 1개 삭제 + .keep 추가만).
