## 1) Hook bootstrap guard (7 파일)

모든 plugin shipped hook 첫 줄에 가드 한 줄 추가:

```bash
[ -d "${CLAUDE_PROJECT_DIR:-$(pwd)}/.ax/hooks" ] || exit 0
```

증상: `.ax/` 가 부분 정리되거나 install 중간 상태에서 `.claude/settings.json` 가 hook 호출 시도 → 매 명령마다 `bash: .../hooks/.../X.sh: No such file or directory` 노이즈. 사용자 첫 인상 trust 침식.

수정: install 진행 중 / `.ax/` 미존재 시 silent exit 0. session cache vs filesystem 불일치 mitigation.

검증: 7 hook (`lint-changed`, `block-destructive`, `grep-on-commit`, `critical-rule-grep`, `check-protected-paths`, `spirit-check`, `triage-nudge`) 모두 `.ax/hooks` 디렉토리 미존재 시 silent exit 0.

## 2) update-state.sh CONVENTION 합산 (인라인 + spirit/rules)

`update-state.sh` 가 root CLAUDE.md 의 `^🔵 \*\*` 만 grep — `@import` 로 위임된 `.ax/spirit/rules/*.md` 의 CONVENTION 룰은 못 잡음. 결과: state.json `convention=0` 영원히, HUD 가 "0 CONVENTION" 표시 (실제 spirit/rules 에 N 개 있어도).

수정:

```bash
CONV_INLINE=$(grep -E '^🔵 \*\*`' "$WS/CLAUDE.md" 2>/dev/null | wc -l | tr -d ' ')
CONV_SPIRIT=0
if [ -d "$WS/.ax/spirit/rules" ]; then
    CONV_SPIRIT=$(grep -hE '^🔵 \*\*`' "$WS/.ax/spirit/rules/"*.md 2>/dev/null | wc -l | tr -d ' ')
fi
CONV=$((CONV_INLINE + CONV_SPIRIT))
```

검증: 인라인 1 + spirit/rules 3 = 4 정확 합산.
