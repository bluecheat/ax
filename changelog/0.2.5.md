# 0.2.5 — 플러그인 전면 정비: SSOT 버그·유령 참조 제거 + smoke 재작성

> 전수 품질 점검(스킬 15개 · 템플릿 페이로드 · 문서 정합)에서 나온 ~50건을 일괄 수정했어요. 핵심은 AGENTS.md SSOT 전환이 소비자 스크립트까지 전파되지 않아 룰 강제·HUD 지표가 조용히 무력화되던 버그와, 폐기된 메커니즘을 살아있는 것처럼 안내하던 스킬 본문의 유령 참조 제거예요.

## 수정 — 동작 버그 (스크립트·설치)

- **`check-rule-enforcement.sh` / `update-state.sh` — AGENTS.md SSOT 미전파**: 두 스크립트가 CLAUDE.md(1줄 alias)만 읽어 신규 설치에서 `rule_count: 0` · L1 지표 0으로 침묵하던 버그. `build-memory.sh` 의 RULES_FILE 해석 체인을 이식해 AGENTS.md 를 우선 읽어요.
- **`up` 재실행 시 `.ax/docs/reference/reference/` 중첩 생성**: `cp -R src dst` 가 기존 디렉토리 안으로 복사하던 문제 → `src/.` 내용 복사로 idempotent 하게.
- **HUD `triage: S×R` 미표시**: statusline 이 아무도 쓰지 않는 `state.json .current_task` 를 읽던 dead code → `.ax/current-task.json` 직접 읽기로 전환 (활성 phase 에서만 표시).
- **`AGENTS.md.template` `[PROJECT_NAME]` 미치환**: up 이 신규 복사 시 프로젝트 디렉토리명으로 치환하는 단계 추가.
- **`install-git-hooks.sh --force --dry-run --json`**: backup 필드 이중 확장으로 invalid JSON 출력하던 버그 수정.
- **`update-state.sh` 표준 위반**: `--help` 가 state.json 을 변조하던 문제 제거, 알 수 없는 인자는 JSON error + exit 1, `GOAX_PROJECT_DIR` 지원.
- **`adr` skill**: BSD sed(`sed -i ''`) 문법 수정 + 인라인 채번을 `next-spec-num.sh --kind adr` 위임으로 전환 (`--kind adr|spec` 옵션 신설, 기본값 spec 은 기존과 동일).
- **`spec-implement`**: 폐기된 `basic` tier 를 jq 기본값으로 부활시키던 라인 제거.
- **승격 임계값 단일화**: `promote-mistake.sh` 가 `.ax/config.yml` `promotion_threshold` 를 읽어요 (기본 3). audit skill 의 하드코딩 `--threshold 2` 제거.

## 변경 — 스킬 본문의 폐기 메커니즘 잔재 제거

- **onboarding**: 존재하지 않는 `output-style.md` 필수 로드 지시 제거(§3.0 인라인 표준이 SSOT), 폐기된 `.claude/rules/` shim 설명을 `spirit-rules-inject.sh` hook 안내로 교체, "hook 이 mistakes 자동 캡처" 주장 제거 (up 완료 메시지 동일).
- **doctor**: 존재하지 않는 `register-hooks.sh`·`docs/spec/hook-registration.md` 참조 제거 — 복구 경로는 `register-spirit-hook.sh` + suggested 병합.
- **hud**: statusline 이 지원하지 않는 `preset` 명령 제거, 예시 출력을 실제 포맷(`triage: M×L2 | harness: 🌟 | ☄2`)으로 교정, refresh 는 `update-state.sh` 호출로 위임.
- **triage**: 게이팅 매트릭스에 S×L2 / S×L3 행 추가 (`references/risk-matrix.md` 와 동기화), 역면접 스킵 룰을 "S/M × L0~L1 만 스킵, L3 는 크기 무관 발동" 으로 모순 해소.
- **mistake**: audit 예약 키워드 "회고" 를 트리거에서 제거 — capture/review 분리 복원.
- **spec**: tier 표에 M×L3 → standard 명시 (`tier-from-state.sh` 와 일치). **spirit**: `## 시작 전 필수` 섹션 추가.
- 스킬·명령·문서 전반의 버전 마커(`(0.x.y — …)` 류) 제거, 폐기 슬래시 트리거(`/setup`, `/doctor` 등) 정리 — 자연어 트리거만 유지.
