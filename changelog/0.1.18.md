# 0.1.18 — brownfield 보호 + spec-validate visibility + friction anti-pattern + install→up rename

## 핵심 변경

도그푸딩에서 발견한 4 cluster 의 plugin bug·gap 정리.

### A. brownfield spirit 보존 (bug fix)

`install` (= `up`) skill 의 §0 line 19-20 선언 ("`.ax/spirit/values.md`, `tone.md` 가 사용자 프로젝트에 이미 있으면 그것을 따라요") 과 §4 의 cp -R 동작이 모순. brownfield 에서 사용자가 회사·팀 톤 customize 했어도 plugin 재호출 시 plain template 로 회귀하는 destructive bug.

수정:
- `templates/default/MANIFEST` 의 `.ax/spirit/` 통째 출고 제거 (재귀 cp 대상 X)
- `skills/up/SKILL.md` §6.10 신규 — `values.md` / `tone.md` / `README.md` 각각 conditional cp (`.suggested` 패턴, `config.yml` / `mistakes/README.md` 와 동일)
- `spirit/rules/` 는 plugin 출고 자체가 없는 사용자 큐레이션 영역이라 X

이로써 doctor → up 흐름이 normal path 라는 design 이 destructive 하지 않게 됨.

### B. spec-validate scope 확장 — 진행률 visibility

기존 게이팅 (NEEDS / placeholder / 빈 섹션) 만으로는 `spec-implement` 우회 commit 후 체크박스 동기화 누락 케이스 못 잡음. 게이트가 거짓말 안 하도록 visibility 추가.

신규 검사 (status 영향 X — `warnings` 배열로 표시):
- `tasks_progress`: `tasks.md` 의 `- [ ]` / `- [x]` 카운트
- `ac_progress`: `spec.md` §3 (성공 기준) AC 의 `- [ ]` / `- [x]` 카운트

`check-spec-clarity.sh` 출력에 `tasks_progress` / `ac_progress` 객체 추가 + `warnings` 배열 신설. `spec-validate` SKILL.md 출력 형식도 진행률 노출.

### C. confirmation-policy.md anti-pattern 박제

룰을 글로만 적고 행동에 안 박으면 거짓말이 됨 — 도그푸딩 turn 에서 발견된 옵션 폭주·결정 재포장·trailing dispatch·zero-change confirm 패턴을 skill 저자 회피 룰로 박제.

"절대 금지" 4 항목 추가 + "Anti-pattern" 섹션 신설 (A1~A4):
- A1 — Cascade option dispatch (한 task 에 옵션 폭주)
- A2 — Decision repackaging (받은 결정 재제시)
- A3 — Trailing dispatch (의례적 마무리)
- A4 — Zero-change confirm (0건 변경 옵션 confirm 요구)

### D. install → up rename

`install` 이라는 이름이 "처음 한 번" 인상을 주지만 실제 동작은 install + idempotent update. doctor → install 재호출이 normal path 인 게 그 증거. 이름이 동작을 거짓말함 → rename.

변경:
- `skills/install/` → `skills/up/`
- `commands/goax-install.md` → `commands/goax-up.md`
- frontmatter `name: up`, description 보강 — `/up` / `goax up` 우선 + 기존 `도입`/`설치`/`셋업`/`하네스 적용` alias 그대로 유지
- Cross-reference 갱신: README.md / README.ko.md / docs/up.md / commands/goax.md / commands/goax-onboarding.md / install.sh / skills/doctor/SKILL.md / skills/onboarding/SKILL.md / templates/default/MANIFEST / tests/smoke.sh

보존 (의도적):
- `/plugin install goax` — Claude Code marketplace native 명령 (우리 통제 X)
- `check-manifest-install.sh` — script 파일명
- `installed $V` / `reinstall` / `install or update` — 영문 명사·시제
