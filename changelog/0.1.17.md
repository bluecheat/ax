# 0.1.17 — doctor 시각화 개편 (emoji 매핑 + Plugin update 단일 y/n + changelog 발췌)

## 핵심 변경

도그푸딩 중 발견한 doctor 출력의 (1) monochrome 가독성 — `✓ · ✗ ⚠` 모두 흑색이라 layer scan 어려움, (2) 버전 sync / 머지 결정이 너무 잘게 쪼개져 인지 부담, (3) 사용자가 [y] 누르기 전에 "무엇이 바뀌는지" 안 보임 — 이 셋을 한 릴리스에서 정리.

### 통합 (3 옵션 → 1 y/n)

- **`_templates drift` + `plugin shipped 자산` + `3-way version drift`** 를 단일 **"🔄 Plugin update 반영"** 섹션으로 통합. 4 가지 따로 묻는 옵션 메뉴 → 단일 `[u] [y/n]` ("전체 업데이트 파일 덮어쓸까요?"). 답이 거의 항상 "yes 동기화" 인데 옵션을 잘게 쪼개는 건 인지 부담만 키움 — 사용자 수정 보호는 git 가 함, doctor 단계에서 분기로 다루지 않아요.

### 신규 (2 항목)

- **changelog 발췌 안내** — version drift 감지 시 `INSTALLED_V < ver <= PLUGIN_V` 사이 `changelog/<ver>.md` 의 첫 줄 (`# X.Y.Z — title`) 을 8 개 cap 으로 노출. `sort -V` 기반 semver 비교. 사용자가 [y] 누르기 전에 "이 업데이트로 무엇이 바뀌는지" 한눈에 보이게.
- **점수 시각화 stacking** — 한 줄에 다 박지 않고 3 줄 스택:
  - 백분율 큰 글자 + 분수 보조 (`90%   (9 / 11)`)
  - 직전 대비 delta (`▲ +7%p vs 직전 호출 (83% → 90%)`) — `state.json:cross_cut.doctor.last_score` 에 저장
  - 해소 항목 (`✅ 해소: version drift · scripts backfill · ...`)

### 폐기 (1 항목)

- **`Mistake audit 주기 점검`** 섹션 통째 삭제 — audit 회고 안내는 `audit` skill 전담 (`/audit`, `goax audit` 직접 호출). doctor 는 mistake 카운트만 표시 (`✅ mistakes/ (N건 누적)`).

### 정리

- **scripts/bash/*.sh 업데이트 명시** — `[u]` action description 에 포함 자산 (`scripts/bash/*.sh · hooks/*.sh · _templates/ · modules/ · docs/`) + `chmod +x` 재적용 + `templates/default/MANIFEST` SSOT 명시. installer `cp -R` 로 이미 커버되지만 사용자 안심용 명시.
- **§3.X 내부 cross-references 정리** — `§3.5`, `§3.7`, `§3.8`, `§3.9` 등 fragile section 번호 참조를 의미 이름으로 교체 ("Plugin update 반영" 섹션, "Sensors — settings.json hook 등록" 섹션 등). plugin SKILL.md 는 섹션 추가/삭제가 잦아 숫자 ID 가 silently 깨질 위험. sample 출력의 `§3.7` leak 도 제거.
