# 0.7.0 — 룰을 읽기 전엔 편집을 막고, 되돌리기 어려운 명령은 사실부터 적게 해요 · spec/ADR ID 가 브랜치끼리 안 겹쳐요

## 무엇이 좋아졌나 — 누구에게 체감되나

- **에이전트가 룰을 안 읽고 고치던 일이 막혀요.** 편집하려는 파일에 걸린 룰(spirit `paths:` · 모듈 룰)을 이번 세션에 한 번도
  Read 하지 않았으면 편집이 막히고, 읽어야 할 파일 목록이 나와요. 읽으면 바로 통과해요.
  한 실사용 프로젝트의 mistakes 22건 중 20건을 사람이 잡았고, 그 절반이 "고치기 전에 조사하지 않음" 이었어요.
  그중 하나는 원문 그대로 "hook 이 읽으라 지시한 룰 파일을 건너뛰고" 였어요 — 안내는 있었는데 건너뛸 수 있었던 거예요.
- **`rm -rf` · `git reset --hard` · `git clean -f` · `git checkout -- <경로>` 같은 명령을 처음 칠 때 한 번 멈춰요.**
  지워질 파일 목록 · 되돌리는 절차 · 사용자 지시 원문을 적고 **같은 명령을 다시 실행하면** 통과해요. 실제 세션에서 모델이
  이 과정에서 추적 안 되던 파일을 스스로 찾아 "복구 불가" 라고 적었어요. `build`·`node_modules`·`target`·`.next`·`__pycache__`·
  `Pods`·`.terraform` 같은 재생성 디렉토리와 프로젝트 밖 경로는 멈추지 않아요.
- **에이전트가 `--no-verify` 로 git 훅을 끄지 못해요.** `git commit -n` · `-c core.hooksPath=` · `git config core.hooksPath` ·
  `HUSKY=0` · `LEFTHOOK=0`/`LEFTHOOK_EXCLUDE` · pre-commit 프레임워크의 `SKIP=` 도 같이 막아요. 사람은 프롬프트에서
  `! git commit --no-verify …` 로 직접 할 수 있어요. 커밋 메시지 속 `-n` 이나 `--no-verify` 글자는 막지 않아요.
- **새 spec/ADR 이 다른 브랜치의 것과 같은 번호를 받지 않아요.** 새 ID 는 `YYYY-MM-DD-<4hex>` 예요
  (예: `.ax/docs/spec/2026-09-25-a3f1-refund-flow/`). 순번은 "지금 디렉토리 최댓값 + 1" 이라 PR 스택·병렬 브랜치가 같은
  번호를 받았어요 — 한 실사용 모노레포에 spec 번호 중복 8개, ADR 번호 중복 12개(`0008` 이 셋)가 있었어요.
  옛 `NNN-slug/` · `NNNN-slug.md` 는 이름을 바꾸지 않고 그대로 읽어요. `--spec` 은 난수 네 자리나 slug 로도 찾아요.
- **모노레포에서 저장소 루트로 연 세션에도 훅이 돌아요.** `.ax/` 가 `projects/<app>/` 에 있으면 루트 `.claude/settings.json` 에
  배선이 있어야 하는데, 손으로 쓰면 새 훅이 생겨도 안 따라와요(실측: 4개 누락). `ade-settings.sh --apply` 가 템플릿에서
  생성하고, doctor 가 어긋남을 보여줘요.
- **세션을 시작하면 알아야 할 것만 짧게 들어와요.** 진행 중인 작업 · 인계 노트 · 설치본이 플러그인보다 낡았는지
  ("`/up` 하세요") · 밀린 audit. 말할 게 없으면 아무것도 안 나와요.
- **모든 훅을 끌 수 있어요.** `.ax/config.yml` `sensors.disabled_hooks: [rule-read-gate]` 로 하나만, `sensors.hook_profile: minimal`
  로 안전망만 남기고, 한 세션만이면 `GOAX_DISABLED_HOOKS=…`. 루트 삭제 같은 복구 불가 차단은 끌 수 없어요.

## 업데이트할 때 알아둘 것

- **세 게이트(`rule-read-gate` · `destructive-facts` · `block-hook-bypass`)는 `sensors.mode: warning` 이어도 막아요.** 통과 조건이
  Read 한 번 · 같은 명령 재실행이라 싸서예요. 원치 않으면 위의 `disabled_hooks` 로 꺼요.
- `/up` 은 기존 `.claude/settings.json` 을 덮지 않고 `.ax/settings.json.suggested` 를 둬요 — 새 훅 4개(`block-hook-bypass` ·
  `destructive-facts` · `rule-read-gate` · `session-start/session-brief`)를 합쳐야 켜져요. doctor 가 빠진 걸 보여줘요.
- 모노레포(세션을 저장소 루트에서 여는 경우)는 `bash projects/<app>/.ax/scripts/bash/ade-settings.sh --check` 로 확인하고
  `--apply` 로 맞춰요. 루트 settings 의 다른 훅·permissions 는 그대로예요.
- 새 설정 키 (없으면 기본값): `sensors.hook_profile` · `sensors.disabled_hooks` · `sensors.rule_gate_exempt`(게이트가 건너뛸 경로) ·
  `sensors.regenerable_paths`(프로젝트의 재생성 경로 — 스택을 가정하지 않으려고 기본값 밖은 프로젝트가 선언해요).
- 두 Bash 게이트의 명령 판정은 python3 를 써요. python3 가 없거나 깨졌으면(macOS xcrun shim 등) 통과시키지 않고 간이 판정으로 막아요.
