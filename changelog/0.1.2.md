# 0.1.2 — 템플릿 이주 (인스턴스 디렉토리 정리)

> 0.1.1에서 정리한 SSOT 원칙 (`_templates/spec/` vs `docs/spec/NNN-/`) 을 module rules · spirit rules에도 일관 적용. 안티패턴 — *인스턴스 디렉토리 안에 템플릿 파일이 섞여 있는 형태* — 제거.

## 이주

| 옛 위치 | 새 위치 |
|---|---|
| `.ax/modules/_TEMPLATE/rules.md` | `.ax/docs/_templates/module/rules.md` |
| `.ax/spirit/rules/_TEMPLATE.md` | `.ax/docs/_templates/spirit/rule.md` |

이제 `_templates/`가 모든 템플릿의 단일 자리예요 (사용자 멘탈 모델: "*템플릿은 한 곳*"):

```
.ax/docs/_templates/
├── adr/0000-template.md
├── spec/{spec, plan, tasks, research, data-model, quickstart, README}.md + checklists/ + contracts/
├── module/rules.md          ← 0.1.2 신설
└── spirit/rule.md           ← 0.1.2 신설
```

## 부수 효과 — 우회 로직 일괄 제거

인스턴스 디렉토리에 템플릿이 없어졌으니 더 이상 *"템플릿 제외 필터"* 가 필요 없어요. 5군데에서 제거:

- `skills/doctor/SKILL.md` 의 spirit 카운트 `grep -v _TEMPLATE`
- `skills/triage/SKILL.md` 의 모듈 매칭 루프 `case "$module_dir" in *_TEMPLATE/*|*_TEMPLATE) continue ;; esac`
- `templates/default/.ax/scripts/bash/update-state.sh` 의 모듈 카운트 `! -path '*/_TEMPLATE/*'`
- `templates/default/.ax/scripts/bash/update-state.sh` 의 spirit 카운트 `! -name '_TEMPLATE.md'`
- `tests/smoke.sh` 의 옛 위치 참조

## 경로 갱신

- `skills/onboarding/SKILL.md`: stub 생성 cp 경로 갱신 — `.ax/modules/_TEMPLATE을 cp` → `.ax/docs/_templates/module/rules.md`를 cp
- `skills/spirit/SKILL.md`: 필수 파일 체크 경로 갱신
- `templates/default/.ax/modules/README.md`: 디렉토리 트리 + 새 모듈 추가 명령 갱신
- `README.md`: 프로젝트 트리 갱신

## 검증

migration 후 smoke:

- `update-state.sh` 동작 시 L2 module count, spirit rules_count 모두 정확 (옛 우회 로직 없이도 자연스러운 결과)
- 새 위치 두 파일 존재 확인
- shell scripts syntax check 통과

## 호환성 — 기존 사용자 영향

- 0.1.1 이하에서 설치된 deployed 프로젝트는 옛 위치(`.ax/modules/_TEMPLATE/`, `.ax/spirit/rules/_TEMPLATE.md`)에 템플릿 파일을 가지고 있을 수 있어요. 새 plugin이 새 위치에서 cp 하므로 옛 파일은 잔재로 남음 — *동작에 영향 없음*. 정리하고 싶으면 직접 삭제:
  ```bash
  rm -rf .ax/modules/_TEMPLATE .ax/spirit/rules/_TEMPLATE.md
  ```
- 사용자가 옛 위치를 cp 원본으로 쓰던 워크플로(`cp -r .ax/modules/_TEMPLATE ...`)는 새 경로로 갱신 필요. 새 명령은 `templates/default/.ax/modules/README.md` 참고.
- triage·doctor·update-state·spirit·onboarding 모두 새 경로로 동작 — 다음 `/plugin install goax` 후 정상 매칭.
