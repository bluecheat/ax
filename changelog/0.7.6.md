# 0.7.6 — 무관한 커밋엔 spec 경고가 한 줄만 · 시크릿 오탐·위치 표시 · 스크래치패드 정리가 막히지 않아요

## 무엇이 좋아졌나 — 누구에게 체감되나

> spec 을 진행하면서 커밋하는 사람, TS·Kotlin·Swift 프로젝트, 레인을 여러 개 띄우는 사람에게 체감돼요.

- **이번 커밋과 무관한 spec 경고가 매번 나오지 않아요.** 활성 spec 의 완료 게이트(`pre-commit/spec-completion-gate.sh`)는
  README 한 줄만 커밋해도 미완료 task·AC 경고를 냈어요. 이제 스테이지 파일이 그 spec 디렉토리 안이거나 tasks.md
  `files:` 경로와 겹칠 때만 자세히 말하고 막아요. 아니면 `spec X 미완료 N — 이번 커밋과 무관해 건너뛰어요` 한 줄만 내고,
  `sensors.mode=fail` 에서도 통과해요.
- **TS 타입 선언이 시크릿으로 잡히지 않아요.** `token: string,` · `messageFor?(…, token: string, …)` 이 CRITICAL 위반이
  되던 것 — 이제 타입 자리는 빼고 보고, `const token: string = "…"` 같은 값 대입은 그대로 잡아요.
  따옴표 없는 YAML 값이 영문자뿐(`secret: MySuperSecret`)이거나 flow 표기(`{token: abc123, …}`)이면 놓쳐요.
- **위반 경고마다 `file:line — 규칙` 이에요.** 시크릿도 줄 번호까지(값은 안 찍어요), 요약 줄에도 앞 3곳의 위치가 실려요.
- **세션 스크래치패드의 빌드 캐시를 지울 수 있어요.** `cd <스크래치패드> && rm -rf Build …; df -h /` 가 뒤의 `df -h /`
  때문에 "재귀 rm + 루트 경로" 로 막히던 것 — 이제 rm 이 든 명령 안에서만 경로를 봐요. 루트·시스템·홈 삭제는 그대로
  막고, `cd / && rm -rf *` · `pushd / && rm -rf *` · 줄 이어쓰기(`rm -rf \⏎ /`)도 막아요.
- **spirit 룰의 `contract:` 를 doctor 가 추적해요.** 룰 frontmatter 에 짝 테스트 경로를 적으면, 테스트 파일이 없거나
  `contract_ids:` 로 적은 SP-ID 가 테스트 본문에 없을 때 `spirit-lint` 가 알려주고, `rules-index` 는 테스트가 막는 룰에 🧪 를 붙여요.
- **레인 브리프에 공용 자원 칸이 생겼어요.** 포매터 `--write` 는 소유 파일만, 브라우저 세션은 레인 이름으로, 빌드 출력은
  코디네이터가 정한 한 경로로 — 레인 하나가 다른 레인 파일을 포맷하거나 세션을 닫거나 디스크를 채우던 일을 막아요.
- **팀원(teammate)으로 띄운 레인은 SendMessage 로 한 번만 보고해요.** 같은 보고가 세 번 오고 idle 통지에서 잘리던 것.
