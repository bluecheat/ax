# 0.1.12 — ops.md opt-in 강등

## 1) `ops.md` plugin 출고 → opt-in 샘플

기존: `.ax/spirit/rules/ops.md` 가 plugin shipped 자산. doctor §3.5.1 drift check 가 사용 안 하는 프로젝트(commerce 등)에서도 매번 "신규 추가 필요" 로 검출.

수정:
- `git mv templates/default/.ax/spirit/rules/ops.md → _templates/spirit/ops.md`
- `templates/default/.ax/spirit/rules/` 는 빈 디렉토리 (사용자 큐레이션 영역)
- `_templates/spirit/` 에 `ops.md` (universal action baseline 샘플) + `rule.md` (작성 가이드 템플릿) 공존

도입 방법: `cp .ax/_templates/spirit/ops.md .ax/spirit/rules/<project>-ops.md` + CLAUDE.md `@import`.

## 2) Doctor §3.5.1 drift check — `spirit/rules/` 제외

`spirit/rules/` 는 사용자 큐레이션이라 plugin shipped drift 검증 대상 아님. drift 디렉토리 목록 `'.ax/scripts/bash' '.ax/hooks' '.ax/spirit/rules'` → `'.ax/scripts/bash' '.ax/hooks'`. 최종 요약 라인도 "4 카테고리 (architecture/data/testing/ops)" 하드코드 → "사용자 큐레이션 N 카테고리" 로 갱신.

## 3) `CLAUDE.md.template` — dead `@import` 정리

`@.ax/spirit/rules/{architecture,data,testing,ops}.md` 4 라인 — 실 출고는 `ops.md` 한 개뿐이었고 이제 그것도 빠짐 (3 라인은 처음부터 dead import). 사용자 큐레이션 안내 + opt-in baseline 위치 (`.ax/_templates/spirit/ops.md`) 안내로 교체.
