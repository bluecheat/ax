# 0.7.1 — lint 결과가 모델에게 닿고, 품질 설정을 몰래 느슨하게 못 하고, 압축 뒤에도 어디까지 했는지 기억해요 · 응답 이모지 정리

## 무엇이 좋아졌나 — 누구에게 체감되나

- **편집한 파일의 lint 실패가 모델에게 보여요.** 예전 `post-edit/lint-changed` 는 결과를 화면 밖에 찍기만 해서 모델이 한 번도 못 봤어요.
  이제 `.ax/config.yml` `commands.lint_file` 에 `"<글롭> => <명령 {file}>"` 을 적으면 그 파일 하나만 검사하고, 실패하면 출력이 모델에게 가요.
  확장자로 도구를 추측하지 않아요 — 폴리글랏·모노레포도 글롭마다 다른 명령(`apps/web/**/*.ts => pnpm --dir apps/web exec eslint …`)을 적으면 돼요.
- **검사를 통과시키려고 lint·format·타입 검사·커버리지 설정을 느슨하게 하는 걸 한 번 멈춰 세워요.** 이미 있는 `.eslintrc*` ·
  `.editorconfig` · `tsconfig*.json` · `detekt*.yml` · `ruff.toml` · `.golangci.yml` · `.husky/` 같은 파일을 세션에서 처음 고칠 때
  "완화인지 강화인지 · 사용자 지시 원문" 을 적게 하고, 같은 파일을 다시 고치면 통과해요. 새 파일은 막지 않아요.
- **컨텍스트 압축 뒤에도 "무슨 파일을 고치던 중이었나" 가 남아요.** 압축 직전에 브랜치·HEAD · 커밋 안 된 파일 · 진행 중 spec 의
  tasks 진행률을 적어 두고, 압축 직후 세션 브리핑 맨 앞에 한 번 보여줘요. LLM 요약이 아니라 사실만이에요.
- **`.ax/settings.json.suggested` 머지가 사용자 훅을 지우지 않아요.** 안내하던 `jq -s '.[0] * .[1]'` 는 `PreToolUse` 배열을 통째로 바꿔서
  사용자 자신의 훅이 사라졌어요. 이제 `ade-settings.sh --apply` 가 단일 저장소에서도 goax 훅 명령만 템플릿대로 맞춰요
  (사용자 훅·permissions·statusLine 은 그대로, 백업 파일은 안 만들어요 — 되돌리기는 git).
- **빌드·테스트·lint 명령을 기억으로 짓지 않아요.** `detect-stack.sh` 가 프로젝트에 적힌 진입점(package.json scripts 와 lockfile,
  Makefile·justfile·Taskfile 타깃, gradlew·mvnw, go.mod·Cargo.toml·pyproject.toml 등과 거기 선언된 도구)에서 후보를 뽑고,
  사용자가 고른 것만 `config-set.sh` 가 `config.yml` 에 적어요. 모르는 생태계는 후보가 비고, 그때는 물어요.
- **같은 종류 실수가 반복되면 세션 첫머리에 알려요.** 미처리 mistakes 중 같은 category 가 2건 이상이면 audit 주기와 상관없이
  "같은 종류 실수 재발: process ×11 · architecture ×4 …" 한 줄이 나와요.
- **doctor 가 매 세션 무조건 실리는 글의 양을 보여줘요.** CLAUDE.md 에서 `@import` 를 따라가 바이트를 더하고(한 실사용 프로젝트 21KB),
  3만 2천 바이트를 넘으면 path-scoped 주입으로 옮길 후보를 제안해요.
- **doctor·onboarding 보고에서 ❌·❗ 가 눈에 띄어요.** 섹션마다 붙던 그림 이모지(doctor 한 파일에 20종)를 `◆` 로 바꾸고, 상태는
  ✅ ❗ ❌ ⛔ 넷, 줄머리는 📍 🎯 📂 👉 넷만 써요. onboarding 질문 박스는 전부 같은 모양이에요.
- **외부 계획 문서와 spec 이 이어져요.** OMC plan 이든 다른 도구든 계획 문서 경로를 `current-task.json` 의 `plan_doc` 에 적으면
  spec 이 "원 계획" 으로 링크해요. spec 부터는 goax 가 관리해요.

## 업데이트할 때 알아둘 것

- 새 훅 2개(`pre-edit/quality-config-gate` · `pre-compact/snapshot`)와 새 이벤트 `PreCompact` 가 생겼어요. `/up` 뒤
  `bash .ax/scripts/bash/ade-settings.sh --check` 로 누락을 보고 `--apply` 로 맞춰요 (모노레포 루트에서 연 세션도 같은 명령).
- `quality-config-gate` 는 `sensors.mode: warning` 이어도 막아요 (통과하는 데 드는 수고가 작아서요). 원치 않으면 `sensors.disabled_hooks: [quality-config-gate]`.
  기본 목록 밖 파일은 `sensors.quality_configs` 글롭으로 더해요.
- `lint-changed` 는 `commands.lint_file` 이 비어 있으면 아무것도 안 해요 — 예전의 확장자별 추측(ktlint·eslint·ruff·gofmt)은 없어졌어요.
  예전 결과는 모델에게 전달되지 않았어서 잃는 건 없어요. `detect-stack.sh` 로 후보를 보고 `config-set.sh --add commands.lint_file "…"` 로 적어요.
- 새 설정 키: `commands.lint_file` · `sensors.quality_configs`. 없으면 기본값이에요.
