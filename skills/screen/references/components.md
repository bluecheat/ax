# 부품 규격 — 16종

부품마다 **흔한 실수 → 표준 형태·수치 → 전/후 → 예외** 순서예요. "이 가이드에 없음" 은 지어내지 않은 자리예요 — 그 자리는 프로젝트 토큰이나 `color-type.md` 의 기본 스케일로 정해요.

- 수치는 1배수 논리 단위예요 (iOS pt · Android dp · 웹 CSS px). 375 폭 기준이고, 2배수(750) 작업 파일이면 두 배로 읽어요.
- 프로젝트에 디자인 시스템이 있으면 **수치는 그쪽이 이겨요.** 이 표는 시스템이 없을 때의 기본값이자, 시스템이 있을 때 "이 값이 실무 범위 안인가" 를 보는 잣대예요.
- 색은 역할 이름(포인트 · 본문 글자 · 보조 글자 · 선 · 면)으로 적어요. 실제 값은 `color-type.md` §기본 팔레트.

## 1. 카드 (상품 · 콘텐츠 · 정보)

- **실수**: 카드 중첩(nested containers) 2~3중, 그레이 배경, 카드마다 짙은 그림자, 내부 글자에 크기 차이가 없음(flat hierarchy), 커머스에서 썸네일 비율 혼용, 호버 시 어두운 오버레이로 상품을 가림 (한 줄에 4개밖에 못 놓고, 마우스가 지나가면 1개는 늘 가려져요).
- **표준**: 흰 바탕 위에 노출. 구획은 1px 선(10~20%). 라운드 4·8·12·16·20. 내부 패딩 16·20·24, 카드 사이 바깥 여백 20~24. 그림자를 쓰면 Y 4~8 / 블러 12~24 / 3~8% (최대 12). 내부 글자 14~16, 가격은 18~24 Bold.
- **상품 카드 세로 순서**: 이미지 → 브랜드명 14 Regular → 상품명 15 Medium → 가격 16~20 Bold → 할인율(위험·할인 역할 색) → 별점·리뷰 12 보조 글자. 별점은 12~14 로 작게. 좌측엔 상품명·옵션, 우측엔 가격·할인율을 마주 보게.
- **전/후**: 중복 프레임 + 그레이 + 짙은 그림자 + 12~13 동일 글자 → 프레임·배경 삭제, 가격 18~24 Bold, 1px 구분선. 호버 오버레이 → 가격·찜·장바구니를 카드 아래 밖으로.
- **예외**: 박스 전체가 클릭 타겟인 부품(아코디언·드롭다운·선택형 옵션 카드)은 컨테이너를 허용해요. 단, 면 + 카드 2중은 여전히 금지 — 1개로.

## 2. 리스트 (행 · 구분 · 썸네일+텍스트)

- **실수**: 행 간격이 타이트, 중앙 정렬로 좌측 기준선 붕괴, 행마다 개별 카드 박스, 날짜·시간 같은 맥락 정보 누락, 시작 여백은 좁고 안 간격만 넓어 퍼져 보임, 행간이 어간보다 좁음.
- **표준**: 좌측 정렬 필수. 요소 간격 8~16, 상하 패딩 12~16. 프로필 32·40·56. 제목 15~16 Medium/Bold, 보조·날짜 13~14 Regular 보조 글자. 구분은 1px 바텀 선(10~20%). 행간 140~150%. 행 높이 56~72 (행 전체가 터치 영역).
- **전/후**: 그레이 카드에 갇힌 행 + 제목과 금액이 같은 12~13 + 시간 없음 → 박스를 제거하고 1px 바텀 선, 금액 16~18 Bold 우측, "오전 10시 33분" 같은 구체 시간 추가.
- **예외**: 스와이프 삭제·넓은 터치가 필요한 인터랙션 리스트는 가벼운 면을 허용해요.

## 3. 캐러셀 · 슬라이드 · 인디케이터

- **실수**: 도트 20개 이상, 인디케이터가 비주얼을 가리는 자리, 56 거대 화살표, 모바일 가로 스크롤 카드가 오른쪽 경계에서 딱 잘려 스크롤인 줄 모름, 8 짜리 짧은 인디케이터.
- **표준**: 인디케이터 바 40~48 × 4, 라운드 100% (원형 도트면 6). 도트가 많으면 얇은 바 하나 또는 숫자(01/06). 화살표 20~24 (터치 프레임 36~44). **엿보기(peek)**: 우측 끝 카드 일부를 잘라 보여 스크롤을 암시해요. 4단 고정 대신 좌우 스와이프.
- **전/후**: 도트 20 + 56 화살표 → 48×4 바, 20~24 화살표 우하단.
- **예외**: 매거진·컨셉 화면은 텍스트와 조합한 대형 원형 화살표 칩을 허용해요 (`bold-mode.md`).

## 4. 배너 (띠배너 · 히어로 · 광고)

- **실수**: 띠배너 닫기 없음 (서브 페이지까지 따라다녀요), 히어로 타이틀 20 으로 강조 부족 또는 이미지를 먹을 만큼 커서 잘림, 밝은 이미지 위 흰 글자 그대로, **그래픽부터 그리고 텍스트를 나중에**, 소수점 좌표로 선이 깨짐, "다른 시안" 이라며 색만 바꿔 옴.
- **표준**: 띠배너 X 터치 44. 히어로 타이틀 일반 48~64 / 매거진 120~300. 높이 300~450. 가독성은 상단 0% → 하단 30~50% 검정 계열 그라디언트 딤.
- **배너 만드는 순서(절대)**: ① 텍스트 배치·중요도 계층(1~4순위)을 100% 먼저 — 그래픽이 없어도 텍스트만으로 뜻이 다 통해야 해요 → ② 그래픽은 보조. 1순위(핵심 혜택) 50~56 Semi-bold/Bold 흰색, 2순위(대상·상품명) 포인트색, 3순위(조건 "당일 지급") 작게 Medium/Regular 보조 글자, 로고는 우상단 작게 흰 단색(20 이하). 반짝이·하트 같은 보조 그래픽은 1~2개. 좌표·크기 소수점 제거, 2배수면 짝수만.
- **시안 방향성 A/B/C**: 배경색·원 하나 추가는 방향이 아니에요. **누끼 조합형 / 통이미지 프레임형 / 텍스트 전용 운영형** 처럼 운영 공수와 프레임 구조가 다른 것을 3~4개.
- **전/후**: 닫기 없는 띠배너 + 20 타이틀 + 가려진 글자 → 44 X, 48/64 타이틀, 하단 30% 딤.
- **예외**: 매거진·브랜딩 웹은 120~400 타이틀과 16:9 풀배열 (`bold-mode.md`).

## 5. 버튼 (주 · 보조 · 텍스트 · 아이콘 · 플로팅)

- **실수**: 높이 20~30, 주·보조 구분 없이 전부 검정이나 원색, 텍스트 버튼에 화살표·밑줄 과다, 글래스라 버튼처럼 안 보임, 좌우 패딩 부족, 글자 10~12, 테두리가 글자보다 두꺼움, **화면마다 규격이 다름** (실측 리뷰의 1순위 결함).
- **표준**: 높이 44~48 (최소 36/40, 주 CTA 48~56). 패딩 상하 12~16 / 좌우 16~32 (좌우 24 이상 권장). 라운드 4·8·12·16 / 캡슐 100%. 글자 14~16 Semi-bold/Medium. **주**: 선명한 단색 채움(검정 또는 포인트색 1개). **보조**: 1px 스트로크 또는 연한 그레이 채움. **텍스트 버튼**: 13~14, 아이콘·밑줄 없이. 스트로크 1~2px.
- **하단 고정 CTA**: 주 버튼 하나는 전폭, 보조가 있으면 보조 : 주 = 1 : 2 비율로 좁은 회색. 색은 주 버튼에만. 뒤 콘텐츠 위로 배경 페이드(24~32) + 스크롤 하단 여백 = CTA 높이 + 하단 여백 + 안전 영역.
- **전/후**: 30 미만 + 구분 없는 글래스/그레이 → 48 · 라운드 12 · 15 Semi-bold 주(솔리드 검정 또는 포인트) + 보조(1px 스트로크).
- **예외**: 매거진은 라운드 0.

## 6. 칩 · 태그 · 뱃지

- **실수**: 칩 글자 18~20 으로 본문보다 큼, 형광·원색 뱃지가 사방, 뱃지가 상품·글자를 가림, 반대로 12×12 뱃지라 체크박스인지 구분 불가.
- **표준**: 높이 24·28·32 (터치가 필요한 필터 칩은 hitSlop·패딩으로 터치 44). 글자 11~13 Regular/Medium. 라운드 100% 또는 4~8. 연한 무채색 배경 + 연한 글자. 긴급·신규만 위험 역할 색 포인트. 스트로크는 정수 (2배수면 2px).
- **선택형 칩**: 선택 하나만 채움 — 검정(다크면 흰) 채움 + Bold, 비선택은 연회색 알약. 포인트 컬러는 칩 선택에 쓰지 않아요 (포인트는 화면에 하나).
- **전/후**: 20 형광 태그가 이미지를 덮음 → 24~28 · 라운드 100% · 12~13 슬림 칩, 긴급은 12 위험 역할 알림 칩.
- **예외**: NEW 뱃지·깜빡임 모션은 긴급·신규 상태에만.

## 7. 탭 · 세그먼트

- **실수**: 탭이 조각조각 분리돼 한 그룹으로 안 보임, 선택 상태 불명, 비선택이 너무 연한 그레이라 대비 붕괴(4.5:1 미만), 탭 글자가 레이아웃 대비 과대, 아코디언 +/− 자리 이탈.
- **표준**: 간격 16~40. 글자 14·15·16 — 선택 Bold + 본문 글자색(또는 흰색), 비선택 Medium + 보조 글자색. 라인형은 하단 2px. **세그먼트**: 전체를 연한 띠(2~6% 불투명도) 하나로 묶고 선택 탭만 흰 채움 + 은은한 그림자(Y 2 / 블러 4 / 6%).
- **전/후**: 파편 탭 + 피드백 불명 → 띠 하나로 통일, 선택 15 Bold + 하단 2px.
- **예외**: 모바일에서 탭이 많으면 가로 스크롤 라인형 탭 — 끝 탭을 엿보기로 잘라 스크롤을 암시해요.

## 8. 입력 폼 (텍스트필드 · 라벨 · 플레이스홀더 · 에러 · 포커스)

- **실수**: 인풋 위에 불필요한 라벨 제목("사용하실 포인트를 입력하세요")으로 공간 낭비, 포커스 상태 선 없음, 지우기 X 없음, 비밀번호 눈 아이콘 없음, 에러도 안 났는데 빨강을 미리 도배, 디폴트와 입력 완료 글자색이 같음, 흐린 회색 글자에 불투명도까지 겹침, 대충 그은 선.
- **표준**: 높이 44~50 (모바일 48/50, 2배수 56). 라운드 0·4·8·12. 선 1px — 비활성은 연한 선, 포커스는 1~2px 선명한 포인트색 또는 검정 (`color-type.md` 의 포커스 링). 글자 14~16. 라벨은 인풋 안 플레이스홀더로 통합하되 **접근성 라벨은 남겨요** (웹 `aria-label`/`<label>`, RN `accessibilityLabel`, iOS `accessibilityLabel`, Android `contentDescription`/`hint`). 우측 끝 X 20~24, 비밀번호 눈 아이콘. **상태값**: 힌트는 보조 글자색 → 입력 완료는 본문 글자색.
- **에러**: 입력을 떠난 뒤(blur) 또는 제출 시에만 표시. 선을 위험 역할 색으로 + 인풋 아래 13~14 문구 (상황 + 행동, `ux-writing.md`). 색만으로 알리지 않고 아이콘이나 문구를 같이.
- **전/후**: 거대 라벨 + 포커스 없음 + X 없음 + 회원가입 문구 잘림 → 라벨 삭제·플레이스홀더 통합, 포커스 선, 20 X, 375 안에 한눈에.
- **예외**: 비밀번호 찾기·시스템 안내처럼 필수 가이드는 인풋 아래 13~14 보조 텍스트를 허용해요. 항목이 많은 폼(주소·결제 정보)은 위 라벨을 유지하는 편이 오입력이 적어요.

## 9. 검색창

- **실수**: 인풋과 검색 버튼이 분리돼 둔탁, 짙은 검정 배경, 지도·메인 위에 56 으로 오버랩, 돋보기가 실시간 검색어 자리에 반대로, 아이콘 크기에 소수점(39.5).
- **표준**: 인풋 우측 안에 버튼·아이콘 통합. 높이 40·44·48·56 (내부 버튼 32~44, 라운드 4~8 / 100%). 좌우 마진 16~24, 내부 패딩 12~16. 아이콘 20~24 라인. 글자 14~16. 검색창엔 돋보기, 실시간 검색어엔 화살표·순위.
- **전/후**: 56 검정 분리형 → 44 흰 통합형 · 내부 32 버튼 · 라운드 4.
- **예외**: 매거진 웹은 GNB 우측 20~24 돋보기 아이콘 → 레이어.

## 10. 드롭다운 · 셀렉트 · 아코디언

- **실수**: 인풋과 셀렉트 높이·폭 불일치, "직접 입력" 케이스 누락, +/− 아이콘 자리 이탈, 펼침 상자에 무거운 그레이 카드, 스펙을 전부 펼쳐 놓아 이미지를 가림.
- **표준**: 셀렉트 높이 44~48 (인풋과 1:1). 토글 아이콘은 같은 좌표에서 변환 (화살표는 180° 회전). 라운드 4~16. **박스 전체가 클릭 타겟**. 글자 14~16. 디폴트 접힘 (1~2줄 요약).
- **전/후**: 직접 입력 없음 + − 이탈 + 26 타이틀 → 직접 입력 추가, 같은 자리 토글, 16~18 타이틀, 전체 타겟화.
- **예외**: 흰 바탕에 1px 선만 긋는 라이트 아코디언.

## 11. 체크박스 · 라디오 · 토글 · 옵션 칩

- **실수**: 체크박스 26 이상 거대, 토글 20 이하로 터치 불가, 옵션·색상 칩 선택 상태 불명, 12 체크박스.
- **표준**: 체크박스·라디오 20·22·24 (26 이상 금지) — 시각 크기와 별개로 행 전체를 터치 영역으로. 토글 높이 28 × 너비 52 (미세 그림자). 옵션·색상 칩 24·28·34. 선택은 1~2px 검정/흰 스트로크(20%) 또는 체크 아이콘. 라벨 13~14 (행 라벨이면 15~16).
- **세 상태**: 선택(포인트색 채움 + 체크 아이콘) / 비선택(빈 칸 1px 30% 선) / 비활성(40% + 라벨에도 사유). 색 하나로만 가르지 않아요.
- **전/후**: 26 체크박스 + 16~20 토글 → 22 체크박스, 28×52 토글, 칩에 체크마크 + 1.5~2px 스트로크.
- **예외**: 좁은 인라인 자리는 18~20.

## 12. 바텀시트 · 모달 · 팝업 · 토스트

- **실수**: 작은 박스 안에 갇힌 스크롤, 인디케이터·X 없음, 어두운 레이어라 바탕과 구분 안 됨, 딤 60% 이상으로 뒤가 안 보임, 320 에서 터짐.
- **표준**: 인디케이터 40~48 × 4 라운드 100%. 상단 여백 0~12, 라운드 16·20·32. 레이어 전체 스크롤 + 상단 정보 슬림 요약 고정. 레이어는 **밝은 톤** (어두운 바탕 위에서도). 딤 20~30% (최대 50). 320 대응: 가로 나열 대신 1줄 수직 또는 2~3개 노출 후 더보기. 최대 높이 화면의 80~90%.
- **닫는 방법 셋을 명세에 문장으로**: ① 인디케이터·헤더를 아래로 드래그 ② 바깥 딤 탭 ③ 우상단 X (터치 44). 하단 고정 CTA 가 있는 시트는 CTA 로도 닫혀요. 라이브러리 이름만 적으면 닫는 법을 적은 게 아니에요.
- **스크롤 소유**: (a) 레이어 전체 / (b) 레이어 내부 독립 + 뒤 화면 고정 / (c) 메인. 하나를 문장으로 적어요.
- **토스트**: 생김새는 이 가이드에 없음 — 프로젝트 토큰으로. 문구 규칙은 `ux-writing.md`. 되돌릴 수 있는 행동(삭제·보관)이면 "되돌리기" 텍스트 버튼을 함께.
- **전/후**: 인디케이터 없음 + 어두운 박스 갇힌 스크롤 → 48×4 바, 흰 레이어 전체 스크롤, 상단 sticky.
- **예외**: 좌측 필터 딤 레이어는 내부 독립 스크롤 + 하단 고정 "적용하기" 필수.

## 13. 헤더 · GNB · 하단 탭바(독바)

- **실수**: GNB 에 글래스·어두운 박스로 비주얼을 가림, 백 버튼 50+, 헤더 프레임 없이 떠 보임, 독바 아이콘 16 이하·굵기 불일치, 독바에 검정/그레이 과다, 찜·공유·구매가 흩어짐.
- **표준**: 헤더 56~64 (2배수 110~112). 비주얼 위 GNB 배경 투명. 백 버튼 24 (프레임 36·40·44). 독바 높이 52~64 (+ 안전 영역), 라운드 100% 또는 16~24, 배경 흰색 또는 60~70% + 블러 20~30, 그림자 Y 4 / 블러 12 / 6%. 웹 GNB 폭 1400~1500 (풀와이드 1920). 상품 상세는 구매·찜·공유를 하단 독바 하나로.
- **전/후**: 50 백 버튼 + 떠 보이는 헤더 + 그레이 GNB → 56 프레임, 24 백(36 프레임), 투명 GNB. 명도 대비가 떨어지는 독바 → 흰색.
- **예외**: 서브 페이지는 투명 대신 1px 바텀 선이 있는 흰 GNB.

## 14. 구분선 · 섹션 헤더 · 더보기

- **실수**: 선 2~3px 로 화면을 조각냄, 0.5px 이하라 고해상도에서 날아감, 섹션 제목 12~14 로 강조 부족, 더보기에 화살표·테두리 박스.
- **표준**: 선 1px, 10~20%. 섹션 제목 20·24·28·32 Bold/Semi-bold. 더보기 13~14 Regular/Medium 텍스트 단독. 섹션 여백 위 32~40 / 아래 80~100 (웹 48·80·120~160). 섹션 사이를 선 대신 8 높이 연회색 띠로 끊는 방식도 허용 — 한 앱 안에선 하나로.
- **전/후**: 2px 진한 선 + 14 제목 + 박스형 더보기 → 1px 10% 선, 28/32 Bold 제목, 14 텍스트 더보기.
- **예외**: 1080 이상 풀배열 웹은 선 없이 40~80 여백만으로.

## 15. 아이콘 · 프로필 · 아바타

- **실수**: 굵기 1/1.5/2 혼용, 면·선 혼용, 프로필 50~64, 문구 옆 장식 아이콘 남발, 가이드 박스 없이 수급해 크기가 들쑥날쑥, 1px 선이 2배수에서 깨짐, 긴 이름 잘림, 로그아웃 화살표 방향 반대.
- **표준**: 굵기 2px (또는 1.5) 통일, 면/선 중 하나. 크기 16·20·24 (터치 프레임 36·40·44). **정방형 가이드 박스**(24·32·48) 안에서 그려요. 프로필 24·32·40. 그라디언트 링: 2px 그라디언트 외곽 + 2px 흰 여백. 이름 잘림은 흰 테두리 + 우측 페이드.
- **전/후**: 1/2px 혼용 + 56 프로필 + 장식 아이콘 → 2px·20~24 통일, 32/40 프로필, 장식 삭제.
- **예외**: 브랜딩 페이지·컨셉 화면은 56 프로필·3D 아이콘을 허용해요.

## 16. 표 · 대시보드 위젯 · 그래프

- **실수**: 바 두께 과다, 위젯 카드 2~3중, 숫자가 그래프에 묻힘, 컨셉이라며 모든 카드에 진한 파란 라인·버튼, 굴뚝 달린 홈 아이콘 같은 과한 일러스트.
- **표준**: 바 16 이하, 선 2px. **숫자가 핵심 정보(primary content)** — 20·24·32·36 Bold. 위젯 라운드 12, 1px 스트로크(10%) 또는 2~6% 그라디언트 채움. 아이콘 20~24, 2px 라인. 브랜드색은 호버·활성에만. 최고·최저 지점에만 원형 도트 + 말풍선 칩.
- **표(Table)**: 전용 수치는 이 가이드에 없음 — 그레이 배경을 제거하고 1px 선만. 숫자 열은 우측 정렬 + 고정폭 숫자(tabular figures).
- **전/후**: 두꺼운 바 + 중복 카드 + 12 숫자 → 16 바, 위젯 흰색, 24~32 Bold 숫자.
- **예외**: 연습용 컨셉 대시보드는 연한 그레이 바탕 뉴모피즘.

## 부록 A. 모든 부품에 공통인 상태 규칙

| 상태 | 시각 규칙 | 놓치기 쉬운 것 |
|---|---|---|
| 기본 | 토큰 값 그대로 | — |
| 눌림 (pressed) | 채움은 한 단계 어둡게(`color-type.md` 의 pressed), 흰 면은 4~8% 회색 오버레이 | 웹 `:active`, RN `Pressable` 의 pressed 스타일, Android ripple |
| 포커스 (키보드) | 포커스 링 2px + 오프셋 2 | 웹 `:focus-visible`. 마우스 클릭엔 안 보이게 |
| 선택 | 굵기 + 채움 또는 체크 아이콘 — 색 하나로만 가르지 않아요 | 선택·비선택이 같은 굵기 |
| 비활성 | 글자·아이콘 40% + 왜 못 누르는지 글로 | 비활성 버튼을 눌렀을 때 아무 안내가 없음 |
| 로딩 | 버튼은 폭 유지 + 스피너, 라벨은 유지하거나 "…하는 중" | 로딩 중 폭이 줄어 레이아웃이 튐 |

터치 영역 44(iOS 44pt · Android 48dp · 웹 44px)는 보이는 크기와 별개예요. 보이는 볼륨은 줄여도 터치 영역은 지켜요 (웹 padding/의사 요소, RN `hitSlop`, iOS `contentEdgeInsets`, Android `TouchDelegate`·`minHeight`).
