# 색 · 글자 · 간격 — 규칙과 디자인 시스템이 없을 때 쓰는 기본 세트

프로젝트에 디자인 시스템(토큰 파일·테마·Figma 변수)이 있으면 **그 값이 이겨요.** 이 파일의 앞쪽(§1~§5)은 어느 시스템 위에서도 통하는 판단 규칙이고, 뒤쪽(§6~§11)은 시스템이 **없을 때 그대로 토큰 파일로 옮겨 쓰는 기본 세트**예요. 이 세트만으로 외부 도구 없이 화면 하나를 끝까지 만들 수 있어야 해요.

## 목차

1. 글꼴 굵기 규칙 · 2. 팔레트 구성 원칙 · 3. 그라디언트 · 4. 어두운 배경·다크 규칙 · 5. 이미지 다듬기

## 1. 글꼴 굵기(Weight)

| 자리 | 굵기 | 비고 |
|---|---|---|
| 메인·코너 타이틀 | Bold / Semi-bold | 시각적 무게(visual weight)를 확실히. 단 120~400 급 대형은 Regular/Light 라야 투박하지 않아요 (`bold-mode.md`) |
| 서브 타이틀·탭·CTA | Semi-bold / Medium | 클릭 가능성과 구획 인지 |
| 본문·보조 | Regular | |

- 영문 타이틀: 대문자 + Regular/Light 가 볼드보다 정교해 보여요.
- 폰트 종류보다 **크기·두께 대비**가 위계를 만들어요. 한 화면 굵기는 2~3단 (Regular · Semi-bold · Bold).
- 주의: 모든 글자에 Medium 만 연달아 쓰면 대비(contrast)가 없어 강조점이 사라져요.

## 2. 팔레트 구성 원칙

- 기초는 **흰 바탕**(또는 연한 무채색) + 글자·여백으로 구획.
- **포인트 컬러 1개** — 가장 중요한 CTA / 선택 탭 / 강조 영역에만.
- 브랜드색을 카드·아이콘·탭·배너 사방에 칠하면 포인트 효과가 사라져요.
- 원색 남용·고채도 과다(oversaturation) 자제. 단정한 대안은 채도를 조금 낮춘 한 가지 색.
- 대비가 강한 이미지(고채도·레드/보라·화려한 인물)가 이어지면 중간에 미니멀·클래식 이미지로 리듬 조절.
- 색은 hex 가 아니라 **역할 이름**으로 지정해요 (`principles.md` A2). 아래 §7 의 역할 체계를 그대로 쓰면 라이트·다크가 같이 풀려요.

## 3. 그라디언트

**쓰는 조건**: 글래스 블러 대체 · 동영상/이미지 위 흰 글자 가독성 · 배경 깊이감.

| 용도 | 수치 |
|---|---|
| 방향 | 45° 대각선 |
| 카드·버튼 미세 | 위 2% ~ 아래 6% |
| 배경 딤(남색·어두운 톤) | 0% ~ 20~30% |
| 동영상·대형 비주얼 하단 가독성 | 흰/검정 10~30% 또는 30~80% |

## 4. 어두운 배경 · 다크 규칙

- 어두운 바탕엔 **검정 배경 블러**. 흰 블러는 지저분해져요.
- 바텀시트·하단 탭바(독바): 불투명도 60~70% + 배경 블러 20~30.
- 대형 미디어 위 GNB 는 배경 박스를 제거하고 **투명**.
- 어두운 바탕 위 팝업·바텀시트는 **밝은 톤**(또는 다크 테마에선 한 단계 밝은 표면)으로 확 띄워야 "떴다" 가 인지돼요. 같은 어두운 톤이면 구분이 안 돼요.
- 다크 테마는 **층이 올라갈수록 밝아져요** (§8). 그림자는 어두운 바탕에서 거의 안 보이니 깊이는 명도 단계로 만들어요. 인접 층 사이 RGB 차이가 8 안팎이면 눈으로 안 갈려요 — 10~16 이상 벌려요 (`measure.md` 면 명도 단계).

## 5. 이미지 다듬기

- **톤다운**: 배경을 깔끔히 후퇴시키고 오브젝트 위주 미니멀 이미지를 섞어 피로를 줄여요.
- **그림자 안착**: 공중에 뜬 상품 아래에 찌그러진 원형 레이어 + 레이어 블러 (불투명도 40% 근처) 로 바닥에 붙여요.
- **누끼 원근감**: 인물·상품 배경을 따고 대형 타이틀을 인물 뒤로 넘겨 배경-타이틀-인물 깊이를 만들어요 (매거진·랜딩 한정).

## 6. 기본 팔레트 — 무채색 스케일 하나 + 포인트 하나

디자인 시스템이 없으면 이 값으로 시작해요. 대비는 흰 바탕(#FFFFFF) 기준 WCAG 2 대비율이에요 (APCA 기준은 `principles.md` C2).

### 6.1 무채색 스케일 (neutral)

| 단계 | 값 | 흰 바탕 대비 | 쓰는 자리 |
|---|---|---|---|
| n0 | #FFFFFF | — | 기본 표면 |
| n50 | #F7F8F9 | — | 눌림 오버레이 바탕, 아주 약한 면 |
| n100 | #F1F3F5 | — | basement 표면, 약한 채움(보조 버튼·칩) |
| n200 | #E6E8EB | — | 구분선(불투명 대체), 약한 채움 pressed |
| n300 | #D1D5DA | — | 입력 테두리, 체크박스 빈 칸 |
| n400 | #ADB3BA | 2.1:1 | 비활성 아이콘 · 비활성 테두리 (글자엔 쓰지 않아요) |
| n500 | #868E96 | 3.3:1 | placeholder · 비활성 글자 (본문엔 쓰지 않아요) |
| n600 | #6B7280 | 4.8:1 | 보조 글자 (캡션·날짜·단위) — 본문 크기에서도 4.5:1 통과 |
| n700 | #4B5563 | 7.6:1 | 강한 보조 글자, 아이콘 기본 |
| n800 | #2B2F36 | — | 다크 elevated 표면 근처, 반전 표면 |
| n900 | #16181C | 17.8:1 | 본문 글자 · 제목 · 무채색 주 버튼 채움 |

### 6.2 포인트 (accent = brand)

| 토큰 | 값 | 대비 | 비고 |
|---|---|---|---|
| accent | #2563EB | 흰 글자 5.2:1 | 채도를 조금 낮춘 파랑 — 프로젝트 브랜드색이 있으면 그 색으로 바꿔요 |
| accent-pressed | #1D4FC4 | | accent 를 명도 약 10% 내린 값 |
| accent-weak | #EAF1FE | | 선택 행·강조 배경 |
| accent-weak-pressed | #D9E6FD | | |
| accent-contrast | #FFFFFF | | accent 채움 위 글자·아이콘 |

포인트를 바꿀 땐 **흰 글자 대비 4.5:1 이상**(채움 버튼 글자)과 **흰 바탕 위 3:1 이상**(아이콘·테두리)만 지키면 이 표의 나머지 구조는 그대로 써요.

**브랜드색이 글자 대비 4.5:1 에 못 미칠 때**:
- 브랜드 색상(hue)을 말없이 바꾸지 않아요. 브랜드색은 글자가 아닌 채움(일러스트 · 배지 바탕 · 선택 표시)과 큰 글자(24 이상 또는 19 Bold 이상, 3:1)에만 그대로 써요.
- 같은 색상에서 명도만 내린 진한 값(예: 브랜드 #FF7A1A → 글자용 #C2410C)을 후보로 만들어 리포트 "결정 필요" 에 올려요.
- 진행은 **새 토큰 안에서만** 해요 — `accent-text` 처럼 새 이름을 만들어 그 진한 값을 담고, 이번 화면의 글자 · 채움 버튼 글자 자리만 그 토큰을 써요.
- 다른 화면이 쓰는 **기존 토큰 값을 진한 값으로 바꾸는 건 ⛔** — 바꾸기 전에 사용자에게 물어요.

## 7. 역할 체계

색은 `{역할}-{강도}` 로 불러요. 역할은 여섯, 강도는 셋 + 눌림이에요.

| 역할 | solid (채움) | solid-pressed | weak (약한 배경) | weak-pressed | contrast (solid 위 글자) | fg (흰 바탕 위 글자·아이콘) |
|---|---|---|---|---|---|---|
| brand | #2563EB | #1D4FC4 | #EAF1FE | #D9E6FD | #FFFFFF | #2563EB |
| neutral | #16181C | #2B2F36 | #F1F3F5 | #E6E8EB | #FFFFFF | #16181C |
| critical | #D92D3A | #B42330 | #FDECEE | #FAD9DD | #FFFFFF | #D92D3A |
| warning | #F59F00 | #D98C00 | #FFF6E0 | #FFEDC2 | #16181C | #B45309 |
| positive | #0B7F45 | #086637 | #E7F6EE | #CFEDDD | #FFFFFF | #0B7F45 |
| informative | #0369A1 | #025683 | #E6F3FA | #CCE6F4 | #FFFFFF | #0369A1 |

규칙
- **화면당 brand solid 는 하나** (주 CTA 또는 선택 상태). 두 번째 강조가 필요하면 neutral solid 로.
- **critical solid 는 되돌릴 수 없는 행동의 확인 버튼에만**. 일반 화면의 삭제 행·에러 문구는 critical fg.
- warning solid 는 밝은 색이라 contrast 가 **어두운 글자**예요 (흰 글자는 2.1:1 로 탈락).
- 상태 역할(critical · warning · positive · informative)은 **아이콘이나 문장과 함께** (`principles.md` C1).
- pressed 는 배경만 바꾸고 글자색(contrast · fg)은 유지해요 (`principles.md` B5).
- 비활성은 역할과 상관없이 하나로: 배경 n100, 글자 n500, 테두리 n300 (`component-systems.md` §0).

## 8. 레이어 표면

깊이는 네 층으로만 나눠요 (`principles.md` B10). 같은 층에서 겹치면 층을 올리지 말고 선으로 구분해요.

| 층 | 쓰는 자리 | 라이트 | 다크 | 깊이 표현 |
|---|---|---|---|---|
| basement | 묶음 목록 뒤 바탕, 설정 화면 배경 | #F1F3F5 | #0B0C0E | 없음 |
| default | 기본 페이지 표면 | #FFFFFF | #16181C | 없음 |
| elevated | 카드·하단 독바·고정 헤더 | #FFFFFF | #1F2227 | 라이트: 1px 선 10% 또는 그림자 Y 4 / 블러 12 / 6% · 다크: 명도 한 단계 |
| floating | 바텀시트·다이얼로그·팝오버·토스트 | #FFFFFF | #2A2E34 | 라이트: 그림자 Y 8 / 블러 24 / 12% + 딤 20~30% · 다크: 명도 두 단계 + 딤 50% |

다크 글자: 본문 #F1F3F5, 보조 #9AA1A9 (#16181C 위 6.8:1), placeholder·비활성 #6B7280. 다크 포인트는 #5B8EF5 (#16181C 위 5.6:1) — 라이트 포인트를 그대로 쓰면 3.4:1 로 어두운 바탕에서 묻혀요.

반전 표면(토스트): 배경 n900 / 글자 n0 / 액션 글자 다크 포인트(#5B8EF5).

## 9. 포커스 링

- 키보드 포커스(`:focus-visible`)에서만 보여요. 마우스·터치로 눌렀을 땐 숨겨요.
- **2px 실선, 포인트색, 요소 바깥 2px 오프셋**. 입력 필드는 테두리 자체를 2px 포인트색으로 바꾸는 방식(안쪽 링)도 허용.
- 포인트 위에 놓인 요소(포인트 채움 버튼)는 링이 묻히니 흰 2px 안쪽 + 포인트 2px 바깥 이중 링.
- 비텍스트 대비 3:1 이상 — #2563EB 는 흰 바탕 5.2:1 로 통과.
- 플랫폼: 웹 `outline` + `outline-offset`, iOS/Android 는 시스템 포커스 표시(하드웨어 키보드·스위치 제어)를 끄지 않는 것이 먼저예요.

## 10. 타입 램프

모바일 본문 16 기준이에요. 행간은 px 로 고정해 두면 큰 글씨 설정에서 비율이 유지돼요 (단위는 웹 rem · RN 의 `allowFontScaling` · iOS Dynamic Type · Android sp 로 사용자 설정을 따라가요 — `principles.md` A4).

| 역할 토큰 | 크기 / 행간 | 굵기 | 자간 | 쓰는 자리 |
|---|---|---|---|---|
| caption-xs | 12 / 16 | Regular·Medium | 0 | 칩·뱃지 안 글자 전용 (본문 문장엔 쓰지 않아요) |
| caption | 13 / 18 | Regular | 0 | 날짜·보조 설명·단위 |
| label | 14 / 20 | Regular·Medium | −0.5% | 보조 본문·라벨·텍스트 버튼 |
| body | 16 / 24 | Regular | −1% | 본문·인풋·리스트 제목 (기준) |
| body-strong | 16 / 24 | Semi-bold | −1% | 버튼 글자·강조 본문 |
| subtitle | 18 / 26 | Semi-bold | −1.5% | 카드 제목·섹션 소제목 |
| title-sm | 20 / 28 | Bold | −2% | 섹션 제목 |
| title | 24 / 32 | Bold | −2% | 시트·다이얼로그 제목 |
| title-lg | 28 / 36 | Bold | −2.5% | 화면 타이틀 (= body × 1.75) |
| number | 32 / 40 | Bold | −2.5% | 핵심 숫자 (가격·잔액) |
| number-lg | 40 / 48 | Bold | −3% | 결과 화면 큰 숫자 |
| display | 48 / 56 | Bold | −3% | 웹 히어로 (모바일 앱에선 쓰지 않아요) |

규칙
- **화면(시트)마다 가장 큰 글자 ÷ body ≥ 1.75** — title-lg(28) 이상이 하나는 있어야 해요. 없으면 number 를 앵커로.
- 한 화면에 쓰는 크기는 3~4단. 표의 12단을 다 쓰라는 게 아니에요.
- 11 이하는 쓰지 않아요. 썸네일이 작아져도 본문은 줄이지 않아요.
- 자간 값은 한글·라틴 혼용 산세리프 기준이에요. 라틴 전용 본문이면 0 으로.
- 데스크톱 웹은 body 15~16 그대로, 타이틀만 32·40·48 로 한 단계씩 올려요.

## 11. 간격 · 반경 · 그림자 스케일

| 종류 | 토큰 → 값 |
|---|---|
| 간격 | space-1 4 · space-2 8 · space-3 12 · space-4 16 · space-5 20 · space-6 24 · space-8 32 · space-10 40 · space-12 48 · space-16 64 · space-20 80 |
| 이름 붙은 간격 | gutter(화면 좌우) 20 · component-gap(부품 안) 8 · group-gap(그룹 사이) 24 · section-gap(섹션 사이) 40 · bottom-safe(하단 CTA 아래) 16 + 안전 영역 |
| 반경 | radius-xs 4 · radius-sm 8 · radius-md 12 (버튼·인풋) · radius-lg 16 (카드) · radius-xl 24 (시트 상단) · radius-full 9999 (칩·토글) |
| 그림자 | shadow-1 Y 4 / 블러 12 / 4% (세그먼트 선택 · 칩처럼 면 안에서 살짝) · shadow-2 Y 4 / 블러 12 / 6% (elevated) · shadow-3 Y 8 / 블러 24 / 12% (floating) — 전부 규칙 범위 **Y 4~8 / 블러 12~24 / 3~12%** 안 |
| 선 | border 1px · 검정 10~20% 또는 n200 |
| 모션 | duration-fast 150ms (눌림·토글) · duration-base 200ms (부품) · duration-slow 300ms (시트·화면 전환) |

간격 스케일 밖의 값(−4 · 10 · 14 · 18 · 60)은 쓰지 않아요. **안 여백 < 바깥 여백** 이라야 그룹핑이 생겨요.

## 12. 토큰 파일로 옮기는 법

토큰은 **한 파일**에 두고, 화면 파일은 이름으로만 가져다 써요 (매직 넘버 금지). 이미 토큰 파일이 있으면 거기에 없는 역할만 추가해요.

| 스택 | 파일 | 모양 |
|---|---|---|
| 웹 (CSS) | `src/styles/tokens.css` | `:root { --color-brand-solid: #2563EB; --space-4: 16px; … }` + `@media (prefers-color-scheme: dark)` 또는 `[data-theme="dark"]` 에서 같은 이름을 다시 정의 |
