빈도가 높은 순서예요. 1~12 는 고빈도, 13~20 은 저빈도 패턴이에요. 순서는 SKILL.md 의 20개 패턴 표와 같아요. 꾸미기 전에 레이아웃 구조(여백·폰트 위계·흰 바탕)부터 세우고, 이펙트(글래스·카드 중첩·원색·드롭섀도우)를 과감히 제거하는 게 스무 개를 관통하는 원칙이에요.

## 1. 글자 크기 과대 · 위계(Hierarchy) 없음

- **증상**: 타이틀·본문·가격·버튼·프로필 이름이 해상도에 비해 커서 잘리거나, 주요 정보와 부가 정보가 전부 20px 근처라 시선이 어디로 가야 할지 모름. 화면이 꽉 막혀 보임.
- **원인**: 강조하려고 무작정 키우거나, 우선순위 없이 모든 요소에 위계 없는(flat hierarchy) 비슷한 크기를 임의 적용.
- **고침**:
  - 메인·코너 타이틀: 과한 64px → 48px 또는 28px. 강조가 부족한 18px → 40/48px. 매거진형이면 120~300px 까지 과감하게.
  - 본문·서브: 24/20px → 15~18px.
  - 버튼·GNB·태그: 20px → 14~16px. 강조 숫자는 볼드, 슬래시·단위(01/06)는 16px 이하로 분리.
  - 가격·핵심 수치: 작아서 안 보이면 오히려 대폭 키워 가장 먼저 인지되게.

## 2. 여백 부족 · 밀도 과다(high density) 레이아웃 밸런스

- **증상**: 요소 사이·프레임 경계와 콘텐츠 사이가 너무 좁거나(−4px 같은 값), 한쪽은 빈 공간 과다, 한쪽은 밀도 과다.
- **원인**: 여백을 디자인 요소로 인식하지 못하고 8pt 같은 체계 없이 임의로 채움.
- **고침**:
  - 부품 내부: 버튼·카드 상하 12~16px / 좌우 16~32px.
  - 요소 간격: 16, 24, 40px 단위. 섹션 사이 위 40px / 아래 80~100px.
  - 비율: 복잡한 영역은 1:1 대칭을 깨고 1 : 0.5 : 0.5 로 메인 배너를 크게.

## 3. 습관적 카드 중첩(nested containers) · 그레이 박스

- **증상**: 정보 묶음을 카드·그레이 배경·라인으로 2중 3중 중첩해 화면의 밀도가 과다하고 명도 대비가 떨어짐.
- **원인**: 흰 바탕에서 글자 크기와 여백만으로 위계를 만드는 기초가 부족해 테두리·회색 면으로 손쉽게 묶으려 함.
- **고침**: 중첩한 프레임과 그레이 박스를 전부 제거하고 흰 바탕에 노출. 구획은 1px 선(불투명도 10~20%)이나 여백 차이로만.

## 4. 이미지 · 썸네일 비율 불일치 · 과대

- **증상**: 위는 정사각형, 아래는 세로 비율 썸네일 혼용. 썸네일·프로필이 필요 이상으로 커서 정보와 시각적으로 충돌하고(competing emphasis) 화면 밖으로 넘침.
- **원인**: 커머스 운영(수천~수만 상품 등록) 효율을 생각하지 않고 화면마다 비율을 바꾸거나, 연출에 치우쳐 볼륨을 키움.
- **고침**: 상품 썸네일 1:1 통일. 프로필 50 → 32px, 컨트롤 버튼 44px, 서브 썸네일 36/64px 로 축소. 공중에 뜬 상품 이미지는 아래에 찌그러진 그림자 레이어(레이어 블러, 40% 근처)로 바닥에 안착.

## 5. 드롭 섀도우 · 이펙트 남용

- **증상**: 부품마다 짙은 그림자가 들어가 전체에 시각적 노이즈(visual noise)가 생기고 명도 대비가 떨어짐.
- **원인**: 입체감을 주려고 오프셋·블러·불투명도를 너무 세게.
- **고침**: 불필요한 그림자 전부 제거. 필요하면 Y 8 / 블러 12~20 / 불투명도 6~15%. 뉴모피즘은 화이트(−10, −10, 100%) + 블랙(10, 10, 20%) 블러 30 쌍으로. 명도 대비를 떨어뜨리는 그림자 대신 1px 연한 스트로크.

## 6. 글래스모피즘 남발

- **증상**: GNB·카드·필터·버튼·그래프·로고까지 뿌연 유리로 도배돼 가독성이 떨어지고 복잡.
- **원인**: 트렌디해 보인다는 이유로 절제 없이 모든 영역에.
- **고침**: 장식 요소 제거(decluttering). 대체는 단색 채움 + 이너 섀도우(X 1, Y 1, 블러 1, 20~25%) 또는 섬세한 45° 그라디언트. 꼭 써야 하는 하단 탭바(독바)·바텀시트만 불투명도 70% + 배경 블러 20~30px.

## 7. 강조 과다 · 브랜드 컬러 난발

- **증상**: 원색(레드·연두·형광 녹색)이 사방에 있거나 모든 이미지·부품의 대비가 강해서 눈이 피로하고 강조점이 없음.
- **원인**: 모든 걸 강조하려다 강약이 무너짐.
- **고침**: 원색 난발 중단. 무채색·어두운 톤으로 배경을 톤 다운(tone down)하고 가장 중요한 CTA·탭 하나에만 포인트. 대비가 강한 이미지가 이어지면 중간에 미니멀한 이미지를 끼워 리듬 조절. 튀는 원색 대신 채도를 조금 낮춘 차분한 강조색 하나 (`color-type.md` 기본 포인트).

## 8. CTA · 아이콘의 강조(emphasis) 부족 / 명확성 결여

- **증상**: 입실하기·장바구니·시청·충전 같은 핵심 버튼이 글래스·연한 그레이에 묻혀 버튼처럼 안 보이거나, 반대로 너무 커서 주변을 압도.
- **원인**: 대비·높이·라운드 규칙 없이 텍스트처럼 방치, 또는 크기 조절 실패.
- **고침**: 높이 44~48px, 라운드 12px 또는 원형, 선명한 블랙/화이트 채움. 과대한 버튼은 상하 패딩 12px, 글자 14px. 긴급 알림은 레드 포인트 + 깜빡임 모션.

## 9. 탭 · 필터 · 아코디언의 위치 · 선택 피드백

- **증상**: 아코디언 열림 아이콘이 엉뚱한 자리로 튀거나, 탭이 조각조각 분리돼 클릭 영역이 모호, 선택 상태 불명.
- **원인**: 같은 자리 토글 원칙과 선택 상태 시각 구조 이해 부족.
- **고침**: +/− 아이콘은 같은 자리에서 토글. 파편화된 탭은 하나의 띠로 묶고 선택은 볼드/화이트, 비선택은 연하게. 버튼형 탭은 하단 2px 라인형(간격 40px). 옵션 선택에 체크 아이콘.

## 10. GNB · 헤더 시각적 무게(visual weight) 과다

- **증상**: 상단 띠배너에 닫기가 없어 계속 가림. 어둡고 큰 GNB·글래스가 메인 비주얼을 여백 없이 덮음.
- **원인**: 헤더는 콘텐츠를 방해하면 안 된다는 점을 간과.
- **고침**: 띠배너에 X(터치 44px). GNB 배경 투명. 바텀시트 상단 바 높이 4px · 너비 48px · 라운드 100%.

## 11. 오버랩 · 지그재그 배치

- **증상**: 동영상 위 이미지 위 텍스트 카드로 3~4중 겹침, 콘텐츠가 좌우 번갈아 지그재그.
- **원인**: '디자인틱한' 레이아웃을 시도하다 가독성과 메인 비주얼을 모두 가림.
- **고침**: 겹침 해제 → 16:9 동영상 노출, 스크롤하면 상품이 깔끔히 덮고 넘어가게 단계 분리. 1080px 풀배열. 지그재그를 제거하고 좌 텍스트 + 우 이미지 일직선, 라인 구분.

## 12. 바텀시트 · 레이어 스크롤 구역 결함

- **증상**: 바텀시트·필터 레이어가 작은 박스 안에서만 좁게 스크롤되거나, 스크롤하면 뒤 화면이 같이 밀림.
- **원인**: 내부 스크롤 vs 메인 스크롤 구조를 계산하지 않고 비주얼 박스만 그림.
- **고침**: (a) 내부 스크롤을 깨고 레이어 전체가 움직이게, 스크롤 시 상단 핵심 정보를 얇게 요약 고정(sticky). (b) 딤으로 메인을 막았으면 레이어 안에 독립 스크롤 + 하단 고정 '적용하기' → 닫히며 목록 갱신.

## 13. 아이콘 굵기·스타일 불일치 · 장식 아이콘 남발

- **증상**: 한 화면에 면 아이콘과 선 아이콘, 1/1.5/2px 굵기가 섞임. GNB·카테고리 문구 옆에 습관적으로 장식 아이콘. 확대해야 예쁜 해외 아이콘이 2배수에서 흐림. 로그아웃 화살표가 들어가는 방향.
- **원인**: 라이브러리·가이드 박스 없이 무료 아이콘을 섞어 씀. 텍스트로 충분한 자리까지 그래픽으로 채우려 함.
- **고침**: 굵기 2px(또는 1.5) 통일, 면/선 중 하나. 정방형 가이드 박스(24·32·48) 안에서 그림. 터치 프레임 40~44, 안의 아이콘 20~24. 장식 아이콘 전면 삭제.

## 14. 타이포 디테일 방치

- **증상**: 행간 Auto 라 두 줄이 뭉침, 어간보다 행간이 좁아 세로로 읽힘, 자간 0%, 영문 타이틀 소문자 흘려 쓰기, 본문·라벨까지 중앙 정렬, 글자가 프레임 끝까지 바짝.
- **원인**: 글자 세부 속성을 안 만짐. 좌측 수직 기준선을 안 세움.
- **고침**: 행간 130~140% 또는 1.5배(어간보다 무조건 넓게). 자간 −2~−3%. 영문 대문자 + Regular/Light. 본문·라벨 좌측 정렬. 긴 문장은 2~3줄, 마진 안에서 말줄임. 한 화면 크기 3~4단, 굵기 2~3단.

## 15. 그리드·정렬·마진 체계 파괴

- **증상**: 카드·부품이 좌측 시작선에서 미세하게 어긋남, 위 24 / 아래 10 처럼 마진 제각각, 한 섹션 안에 중앙·좌측 정렬 혼용, 화면이 조각나 보임.
- **원인**: 12/16컬럼 가이드와 오토레이아웃 마진 규칙 없이 눈대중.
- **고침**: 1080/1280/1440 컬럼 라인 설정, 모든 요소 좌측 시작선 일치. 좌우 마진 16·20·24, 코너 상하 32·40. 정렬은 좌측 기본, 카드 안에선 좌 상품명 / 우 가격 마주 보기.

## 16. 이미지 위 글자 가독성 · 상품 안착 · 이미지 품질

- **증상**: 밝은 이미지 위 흰 글자가 묻힘. 신발·상품이 그라운딩 없이 떠 보임. 이미지를 비율 무시하고 늘려 찌그러짐(351×360 같은 애매한 프레임). 요소가 어지러운 "예쁜" 이미지.
- **원인**: 오버레이·그림자·원근을 계산 안 하고 그대로 배치. 넓은 배너 프레임에 리터치 없이 끼움.
- **고침**: 상단 0% → 하단 30~50% Black/Dark Blue 그라디언트 딤, 또는 10~30% + 블러 10~20, 또는 글자 뒤 30~50% 칩. 상품 아래 타원 + 레이어 블러 20~50 / 30~40%. 비율 파괴 대신 포토샵 생성형 채우기로 좌우 확장. 포커스가 가운데 하나이고 여백이 깨끗한 이미지만. 대비가 강한 이미지 옆엔 연한 이미지.

## 17. 폼 상태·컨트롤 미설계

- **증상**: 포커스 선 없음, 지우기 X 없음, 비밀번호 눈 없음, 디폴트와 입력 완료 글자색 같음, 검색 버튼이 인풋 밖에, 인풋 위 거대 라벨, 에러 전부터 빨강.
- **원인**: Focus → Typing → Clear → Action 상태 변화를 안 그리고 정적인 박스만.
- **고침**: 포커스 1~2px 선명한 선, 우측 X 20~24 + 눈 아이콘, 힌트 그레이 → 완료 #111, 검색 버튼을 인풋 안 우측(32~44), 라벨은 플레이스홀더로.

## 18. 모바일 첫 화면 잘림 · 320px 미대응 · 소수점

- **증상**: 375×812 첫 화면에서 로그인 버튼·회원가입 문구가 스크롤 아래. 390 프레임으로만 작업해 320 에서 겹침. 좌표·크기에 15.2 같은 소수점이라 선이 흐림.
- **원인**: 첫 화면 가용 높이를 계산 안 함. 최소 해상도 예외를 안 봄. Scale 뒤 정수 정리 안 함.
- **고침**: 상단 여백·인풋 패딩 축소로 첫 화면 안에 전부. 320 은 가로 나열을 1줄 수직이나 스와이프로. 소수점 제거, 2배수는 짝수만, 2배수 선·아이콘 최소 2px.

## 19. 정보 순서·개념 오류 (커머스·결제·대시보드)

- **증상**: 상품 카드에 브랜드·별점·가격·할인·태그가 무작위, 별점이 가격 위에 거대. 주문서에서 최종 금액과 적립을 묶고 할인을 따로, 할인에 − 없음. 대시보드 숫자가 그래프에 묻힘, 바가 두꺼움.
- **원인**: 이용자의 시선 흐름과 영수증 구조(상품금액 − 할인 = 최종 → 적립)를 이해 못 하고 임의 배치. 숫자가 핵심 정보(primary content)임을 간과.
- **고침**: 카드 이미지 → 브랜드 14 → 상품명 15 → 가격 16~20 Bold → 할인 Red → 별점 12. 영수증 총액 → 할인(−, Red) → 최종(대형 Bold) → 적립(+). 바 16 이하, 숫자 20~36 Bold, 위젯 배경 비움.

## 20. 예외 케이스·확장성·리듬 미고려

- **증상**: 카테고리명 10글자 넘으면 깨짐, 천만 단위 가격에 틀이 터짐, 모듈 5~6단에서 겹침, 같은 4단 모듈 무한 반복으로 와이어프레임 같음, 선택 칩 초기화 없음, 화면마다 인풋·버튼 규격이 다름, "다른 시안"이라며 색만 바꿈.
- **원인**: 짧은 더미 텍스트 기준 정적 설계. 공통 UI 개념 없음. 스타일 변형과 구조 변형을 구분 못 함.
- **고침**: 최대 글자 수 하나 정하고 말줄임 설계, 5단까지 대응 후 6단 분기, 반복 사이에 블랙 면 코너·띠배너 1~2개, 전체 삭제 버튼, 버튼·인풋 공통 규격(40/48/56)과 디폴트/호버/선택/완료 상태, 시안은 누끼 조합형·통이미지형·텍스트 운영형처럼 구조가 다른 A/B/C.

## 그 밖의 지적 (패턴으로 세우기엔 빈도가 낮음)

- **컨셉보드·뉴모피즘 복사** — 개발·스크롤이 불가능한 3D·위젯 장식을 실무 시안이라고 냄. 웹 1080/1920·모바일 375 규격의 사용성 있는 UI 로.
- **포트폴리오 기교 편중** — 퍼블리싱 기교는 화려한데 문제 정의·리서치·UI 근거가 비어 있음. PDF 로 바꿔서라도 기획력에 집중.
- **누끼·Depth 미활용** — 대형 타이틀을 인물 뒤로 넘기는 원근감. 매거진·랜딩 한정.
- **호버 오버레이** — 상품 위 어두운 오버레이 + 아이콘. 4개밖에 못 놓고 1개는 항상 가려짐. 가격·찜·장바구니를 카드 아래 밖으로.
- **3D 그래픽 이너 섀도우 1개** — 입체감 없이 무료 이미지처럼. 3~4개 적층(좌상 반사광 화이트 70~80%, 우하 어둠 20~50%). 배너·아이콘 그래픽 한정.
