# 잘한 예 · 금지 · 조건부 허용

리뷰 리포트의 "잘한 것" 과 "금지" 를 쓸 때 근거로 써요. 조건부 허용을 쓴 곳은 리포트에 허용 조건을 한 줄로 적어요. 파격 허용 화면의 상세는 `bold-mode.md`.

## (A) 잘한 예

| 무엇 | 왜 좋은가 |
|---|---|
| 리뷰 요청에 페이지 성격과 유저 플로우를 글로 정리해 첨부 | 기획 의도·로직을 바로 이해, 피드백 효율↑ |
| 디자인 도구의 누끼·AI 로 인물 배경 분리 | 타이틀을 인물 뒤로 넘기는 원근감 연출이 가능해짐 |
| 넓은 여백의 과감한 대형 이미지·타이틀, 매거진 레이아웃 시도 | 갇힌 디자인보다 컨셉에 맞는 방향성 |
| 팝업·바텀시트를 어두운 톤 대신 밝은 톤으로 띄움 | 레이어가 떴다는 인지와 내부 가독성이 선명 |
| 뉴모피즘 위젯의 시계 컴포넌트 디테일 | 이너 섀도우·미세 라인으로 질감을 살리기에 가장 적합 |
| 요금제에서 가격을 대형 타이틀로 | 핵심 정보(primary content)를 직관적으로 |
| 컨셉보드 슬라이드 인디케이터 6px | 거대한 요소 사이 보조 요소 배율이 적정 |
| 커머스 목록에서 필터를 상단으로 | 상품 비주얼 영역 최대화 + 필터 탐색 |

## (B) 금지

| 규칙 | 이유 |
|---|---|
| 커머스 상품 목록에서 썸네일 비율을 혼용하지 않는다 | 화면마다 새 비율을 쓰면 수천~수만 상품 운영이 불가 |
| 글래스를 GNB·카드·필터·버튼·그래프까지 도배하지 않는다 | 글래스 남발은 가독성과 완성도를 떨어뜨린다 |
| 타이틀과 탭을 시각적으로 충돌(competing emphasis)시키지 않고, 가격을 구석에 두지 않고, 모든 플랜 버튼을 똑같이 강조하지 않는다 | 핵심 정보가 묻히고 강약이 사라진다 |
| 브랜드 원색을 사방에 칠하지 않는다 | 포인트 컬러의 효과가 소멸한다 |
| 카드·그레이 컨테이너를 2중 3중 중첩하지 않는다(nested containers) | 위계·여백 규칙이 없을 때 나오는 가장 쉬운 연출이고, 방향 자체가 잘못됐다 |
| 사용성 없는 해외 컨셉보드·무드보드를 실무 시안으로 내지 않는다 | 동작 구조가 없어 피드백할 근거가 없다 |
| 한 화면 모든 요소를 강하게 강조하지 않는다 | 모든 걸 강조하면 밸런스가 깨진다 |
| 딤으로 화면을 막아 놓고 스크롤 구역을 나누지 않은 채 전체 스크롤하게 두지 않는다 | UX 자체가 성립하지 않는 불가능한 구조 |
| 좌-우-좌-우 지그재그로 배치하지 않는다 | 시선 흐름을 깨는 가장 흔한 실수 |

## (C) 조건부 허용

| 원래 제한 | 허용 조건 |
|---|---|
| 글래스모피즘 — 카드·GNB·필터에선 제거 | 모바일 하단 탭바(독바)·바텀시트에서만 불투명도 60~70% + 배경 블러 20~30px, 또는 1px 이너 섀도우로 대체 |
| 대형 폰트 120~400px — 일반 UI 는 48 이하 | 패션 매거진·비주얼 브랜딩 웹에서 타이포 예술성·원근감 목적 |
| 세로 썸네일·비대칭 비율 — 커머스는 1:1 | 매거진·미디어 웹의 리듬·파격 연출, 16:9 동영상 풀배열 |
| 뉴모피즘·입체 그림자 — 실무 UI 에선 안 씀 | 감각 훈련용 컨셉보드, 연한 그레이 바탕, 화이트(−10,−10,100%)+블랙(10,10,20%) 블러 30 정확히 |
| 카드 컨테이너로 전체 묶기 — 기본 금지 | 드롭다운·아코디언처럼 박스 전체가 클릭 타겟인 인터랙션 부품 |
| 이미지 위 딤·오버랩 — 비주얼을 가리면 금지 | 동영상·고채도 이미지 위 텍스트·버튼 가독성용 10~30% 은은한 그라디언트 딤 |
