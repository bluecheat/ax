# 파격 허용 모드 — 랜딩 · 포트폴리오 · 브랜딩 · 매거진

이 skill 의 기본은 **절제**예요. 파격은 화면 종류가 허용할 때만 켜요 — 사용자가 "멋지게" 라고 했다고 켜지 않아요. 켰더라도 게이트(글자 비율 · 간격 스케일 · 터치 44 · 문구 · 대비)는 하나도 면제되지 않아요. 파격은 **위계를 더 세게 세우는 방법**이지 위계를 버리는 허가가 아니에요.

## 목차

1. 켜는 조건과 끄는 조건 · 2. 먼저 방향 하나를 정해요 · 3. 타이포그래피가 이끄는 레이아웃 · 4. 비대칭 그리드 · 5. 이미지 · 6. 색 · 7. 모션 — 절제 · 8. 그래도 지키는 게이트 · 9. 흔한 실패 · 10. 리포트에 적을 것

## 1. 켜는 조건과 끄는 조건

| 켜요 (파격 허용) | 끄요 (절제) |
|---|---|
| 랜딩 · 브랜드 소개 · 캠페인 페이지 | 커머스 목록·상세·결제 |
| 포트폴리오 · 케이스 스터디 | 업무 앱 · 대시보드 · 관리자 |
| 매거진 · 에디토리얼 · 아카이브 | 설정 · 폼 · 마이페이지 |
| 행사·전시·제품 출시 한 페이지 | 온보딩 · 로그인 · 결과 화면 |

한 서비스 안에서도 갈려요 — 브랜드 랜딩은 파격, 그 랜딩의 "구매하기" 뒤 결제 흐름은 절제. 모드를 리포트 첫머리에 근거와 함께 한 줄로 적어요.

## 2. 먼저 방향 하나를 정해요

파격 화면이 실패하는 가장 흔한 길은 기법을 여러 개 섞는 거예요 (큰 글자 + 그라디언트 + 3D + 지그재그). **방향은 하나**만 골라 끝까지 밀어요.

| 방향 | 무엇이 주인공인가 | 잘 맞는 곳 | 핵심 장치 |
|---|---|---|---|
| 타이포 주도 (typographic) | 글자 자체 | 슬로건이 강한 브랜드, 에이전시, 행사 | 120~300 표제, 극단적 크기 대비, 넓은 여백 |
| 에디토리얼 (editorial) | 글과 이미지의 리듬 | 매거진, 케이스 스터디, 블로그 | 다단 그리드, 큰 인용구, 캡션 체계 |
| 이미지 주도 (image-led) | 사진·영상 한 장 | 패션, 공간, 제품 출시 | 풀블리드 이미지, 최소 텍스트, 하단 딤 |
| 구조 노출 (structural) | 그리드·선·숫자 | 포트폴리오, 아카이브, 기술 브랜드 | 보이는 그리드 선, 번호 매김, 고정폭 숫자 |

색다르게 보이려고 쉬운 구도를 꼬지 않아요. 고른 방향이 이 브랜드의 무엇을 말하는지 한 줄로 적을 수 있어야 해요.

## 3. 타이포그래피가 이끄는 레이아웃

- **크기 대비를 극단으로**: 표제 120~300 (모바일 56~96) 대 본문 16~18. 비율은 1.75 가 아니라 5~15배까지 가요. 중간 크기를 없애야 대비가 살아요 — 표제·본문·캡션 세 단만.
- **대형 표제는 가는 굵기**: 120 이상은 Regular / Light. Bold 대형은 투박하고 무거워요. 영문이면 대문자 + 자간 −2~−4%.
- **행간을 좁게**: 대형 표제는 행간 90~105%. 본문 행간(150%)을 그대로 쓰면 줄이 흩어져요.
- **한 줄에 한 생각**: 표제를 의미 단위로 직접 줄바꿈해요 (자동 줄바꿈에 맡기지 않아요). 한국어는 어절 단위 (`locale-ko.md`).
- **글꼴은 둘까지**: 표제용 하나(개성 있는 세리프나 디스플레이 산세리프) + 본문용 하나(가독성 좋은 산세리프). 표제 글꼴로 본문을 쓰지 않아요.
- **반응형 크기**: 웹은 `clamp(56px, 12vw, 240px)` 처럼 폭에 따라 줄이고, 320 폭에서 한 단어가 화면을 넘지 않는지 확인해요.

## 4. 비대칭 그리드

- 12컬럼은 그대로 두고 **배치만 비대칭**으로: 7 : 5, 8 : 4, 또는 1 : 0.5 : 0.5. 무작위 배치가 아니라 같은 컬럼 선에 시작점을 맞춘 비대칭이에요.
- **여백이 요소**예요: 섹션 사이 120~200 (모바일 80~120). 화면의 40% 이상을 비워 두는 섹션이 있어도 돼요.
- **오버랩은 한 군데만**: 표제가 이미지 위로 걸치는 연출은 페이지에 하나. 둘 이상이면 지그재그와 같은 실패예요.
- **스크롤 리듬**: 큰 섹션 · 작은 섹션 · 풀블리드 이미지를 번갈아 두고, 같은 레이아웃 섹션을 세 번 연달아 두지 않아요.
- 모바일에서 비대칭은 대개 1컬럼으로 접혀요. 접힌 뒤에도 정보 순서(표제 → 핵심 가치 → 증거 → CTA)가 유지되는지 확인해요.

## 5. 이미지

- **한 장을 크게**: 작은 이미지 여러 장보다 풀블리드 한 장. 16:9 · 3:2 · 세로 4:5 혼용은 매거진에선 허용 — 커머스 목록에선 여전히 금지.
- **톤을 맞춰요**: 색온도·채도·대비를 한 결로. 결이 다른 사진이 섞이면 브랜드가 흩어져요.
- **글자 위 가독성**: 이미지 위 표제는 하단 0 → 30~50% 딤, 또는 글자를 이미지의 빈 영역에 배치. 대비는 큰 글자 3:1 이상.
- **누끼 깊이**: 배경 – 표제 – 인물 3층 연출은 페이지에 한 번.
- 비율이 안 맞으면 늘이지 말고 리터치로 확장하거나 다시 크롭해요.
- 무거운 이미지는 `loading="lazy"` · 적절한 해상도 · 최신 포맷으로. 첫 화면 히어로만 즉시 로드.

## 6. 색

- 파격 모드여도 **강조는 하나**. 강한 색을 넓은 면(배경 전체)에 쓰는 대신 다른 곳은 무채색으로 비워요.
- 배경을 흰색이 아닌 색(크림 · 먹색 · 강한 단색)으로 바꾸는 건 허용 — 그때 그 배경 위 글자 대비를 다시 재요.
- 그라디언트는 하나의 방향, 두 색까지. 무지개·메시 그라디언트를 섹션마다 바꾸지 않아요.

## 7. 모션 — 절제

- **한 페이지에 대표 모션 하나**: 히어로 등장, 스크롤에 따른 표제 이동, 이미지 마스크 열림 중 하나. 섹션마다 다른 등장 효과를 주지 않아요.
- 길이: 부품 200ms 이하, 섹션 등장 300~600ms, 그 이상은 건너뛸 수 있게 (`principles.md` B9 · C7).
- **reduced-motion 에선 끄고 최종 상태로** 보여 줘요. 모션이 있어야만 읽히는 정보는 없어야 해요.
- 스크롤 하이재킹(스크롤 속도·방향을 빼앗는 것) 금지. 패럴랙스는 이동량 작게 (20~40px).
- 자동재생 영상은 음소거 + 정지 버튼.

## 8. 그래도 지키는 게이트

| 게이트 | 파격 모드에서의 모양 |
|---|---|
| 가장 큰 글자 ÷ 본문 ≥ 1.75 | 오히려 훨씬 넘어요. 넘지 못하면 파격이 아니라 평평한 화면이에요 |
| 간격 스케일 안 | 스케일을 위로 늘려요 (96 · 120 · 160 · 200). 스케일 밖 임의값은 여전히 금지 |
| 터치 44 | 큰 화살표 칩·텍스트 링크 CTA 도 터치 영역 44 |
| 포인트 하나 | 넓게 쓰더라도 하나 |
| 대비 | 이미지 위 글자 · 컬러 배경 위 글자 모두 재요 |
| 문구 · 금지어 0건 | 슬로건은 카피라이팅이어도 되지만, 버튼·오류·폼 문구는 UX 라이팅 규칙 그대로 |
| 320 · 긴 문자열 | 대형 표제가 320 에서 넘치지 않게 |
| 첫 화면 | 1080 세로(모바일 첫 화면) 안에 표제 + 키비주얼 + CTA 가 한눈에 |

## 9. 흔한 실패

- 기법을 다 쓰기 — 대형 글자 + 3D + 글래스 + 지그재그 + 그라디언트.
- 컨셉보드 한 장을 실무 시안으로 내기 — 스크롤·상태·320·반응형이 없음.
- 대형 Bold 표제로 투박하게.
- 모든 섹션에 다른 등장 모션.
- 표제가 멋있어서 CTA 를 잊기 — 랜딩도 다음 행동이 하나 있어야 해요.
- 이미지를 늘려 찌그러뜨리기.

## 10. 리포트에 적을 것

- 모드 판정 근거 한 줄 ("브랜드 랜딩 — 파격 허용").
- 고른 방향 하나와 이유 ("타이포 주도 — 슬로건이 제품 정체성").
- 게이트 표는 절제 모드와 같은 행 그대로. 파격이라 면제한 행은 없어요.
