# Output Style — clack 스타일 prompt 표준

## 원칙

좌측 vertical bar `│`로 한 prompt에 속한 모든 줄을 시각 연결. 시작 `◆`, 끝 `└`. 섹션 구분 `├─ 섹션 ─`. 옵션은 `●`(선택중·권장) / `○`(미선택). 이모지로 시맨틱 색상 대체 (Claude Code 응답 영역 ANSI 미보장).

## Box-drawing 글리프

| 글리프 | 용도 |
|---|---|
| `◆` | prompt 시작 (헤더) |
| `│` | 좌측 vertical bar (모든 본문 줄) |
| `├─ ─` | 섹션 구분 (예: `├─ 옵션 ─────`) |
| `└` | prompt 끝 (입력 마커 직전) |
| `▸` | 사용자 입력 유도 |
| `●` | 옵션 선택중·권장 |
| `○` | 옵션 미선택 |
| `◼` | 다중 선택 (체크됨) |
| `◻` | 다중 선택 (미체크) |

## 시맨틱 이모지

| 이모지 | 의미 |
|---|---|
| 📍 | 발견·관찰 (사실 보고) |
| 🎯 | 목표·의도 |
| 📂 | 영향 받는 파일·디렉토리 |
| ⚡ | 큰 변경 (파일 수, 위험) |
| ✓ | 장점·통과·성공 |
| ⚠ | 위험·단점·주의 |
| ❌ | 차단·실패 |
| 🔴 | CRITICAL 시그널 |
| 🟡 | MANDATORY 시그널 |
| 🔵 | CONVENTION 시그널 |
| 🌕 | 활성 (HUD 우주 이모지) |
| 🌑 | 비활성 (HUD 우주 이모지) |
| 🪐 | 관련 ADR (HUD) |
| → | 다음 단계 |

## 헤더 패턴 (질문·진단 시작)

```
◆  Q<N>/<TOTAL>   <짧은 제목>                · <이전 답 요약 (있을 때만)>
│
```

진행 표시 없는 단발 prompt:

```
◆  <skill 이름> — <한 줄 요약>
│
```

## 본문 — 발견 + 목표

```
│  📍 발견
│   <사실 1>
│   <사실 2>
│
│  🎯 목표
│   <의도 한두 줄>
│
```

## 옵션 섹션

```
├─ 옵션 ────────────────────────────────────────────
│
│  ●  [a]  <옵션 한 줄>                                   ✓ 권장
│      <부가 설명 1줄>
│      📂 <영향 파일/디렉토리>
│      ⚠  <위험·단점>
│
│  ○  [b]  <옵션 한 줄>
│      ⚡ <변경 규모>
│      ✓ <장점>
│
│  ○  [c]  <옵션 한 줄>
│
```

규칙:
- 권장 옵션은 `●` + 우측 `✓ 권장`
- 미선택은 `○`
- 옵션 사이 빈 줄 (`│`만 있는 줄) 1개로 시각 분리
- 부가 설명은 본문보다 한 칸 더 들여쓰기 (옵션 라벨과 정렬)

## 입력 마커 (prompt 끝)

```
└  ▸  답해주세요   [a] / [b] / [c]
```

복수 선택 가능 시:

```
└  ▸  답해주세요   복수 가능: a,b / 또는 [e] 보류
```

## ✓ 메시지 (작업 완료 후)

각 Q/단계가 끝났을 때:

```
◆  Q<N> 완료   <한 줄 요약>
│  📂 <생성·수정 파일 N개>
│  ✓  <보존된 것>
└  → 다음: <다음 단계 안내>
```

## 안티패턴

- 이모지 mixed (`★ ✓ ⚠ N` 섞기 — `N`은 의미 모호) → 시맨틱 표 참조
- 옵션 사이 빈 줄 없음 (모두 같은 들여쓰기 → 시각 구분 약함)
- 들쑥날쑥 정렬 → 모든 옵션 본문 같은 들여쓰기
- 좌측 vertical bar `│` 누락 → prompt 연속성 시각화 X
- 상태 정보를 텍스트로만 (`(선택됨)`) → `●`/`○` 글리프로

## 적용 범위

모든 plugin skill의 인터랙티브 출력:
- onboarding (Q1~Q5)
- triage (옵션)
- audit (승격 후보)
- doctor (다음 단계)
- spec-new (tier 옵션)
- spec-validate (재검사 옵션)
- installer (Plan)

본문 산문(설명·가이드)은 일반 마크다운. *프롬프트만* clack 스타일.
