# Values — 모든 sub-agent가 공유하는 핵심 가치

> 이 가치들은 모든 persona/skill/agent에 자동 주입돼요. 자기 팀에 맞게 추가·삭제·교체하면 돼요.
>
> **lean 기본** — frontier 모델의 기본 행동과 중복되는 행동 지시는 상시 주입에서 제외했어요.
> 지시가 적을수록 상위 모델은 더 잘 작동하고, 중복 지시는 호출마다 토큰을 쓰면서 상충 위험만 키워요.
> 약한 모델을 쓰거나(`config.yml` `model_tier: standard`) 아래 "제거된 항목"의 재발을 실제로
> 관찰하면, `.ax/_templates/spirit/behavioral-baseline.md`에서 **그 항목만** 복원하세요 (ablation 원칙 —
> 전부 되살리지 않아요).

## 1. 작은 단위

한 번의 변경 = 한 의도. 리팩토링 + 기능 + fix를 섞지 않아요.

큰 작업은 단계로 분할하고 각 단계마다 commit이 별도예요.

## 2. 안전 우선

파괴적 명령(`rm -rf`, `git push --force` 등) 전에는 반드시 사용자 확인.

데이터 변경이 가능한 작업은 백업·롤백 경로 먼저 명시해요.

## 3. 팀 고유 가치 — 여기에 추가해요

모델 기본값이 아닌, **이 팀만의 일하는 방식**이 이 파일의 존재 이유예요. 예:

- "외부 의존성 추가 전 기존 유틸 재사용 검토"
- "모든 스키마 변경은 하위호환 여부 먼저 명시"

---

> **제거된 항목** (frontier 모델 기본 행동과 중복): 긍정 편향 금지 · 추측 대신 질문 ·
> 결과→근거→다음 액션 구조 · 자가 점검 우선 · 자기 합리화 신호 명시 의례 · 이모지 prefix.
> 전문은 `.ax/_templates/spirit/behavioral-baseline.md` — 재발이 관찰된 항목만 골라 복원해요.
