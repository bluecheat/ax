# 가치 가설 · 위험 가정 순위

> 0→1 에서 가장 비싼 실수는 **틀린 걸 잘 만드는 것**이에요. 이 문서는 "무엇이 참이어야
> 이 제품이 서는가" 를 한 문장으로 못 박고, 그 문장이 틀렸을 때 **어떻게 알 것인지**를 정해요.
> 반증 신호가 없는 가설은 가설이 아니라 소망이에요.

## 1. 가치 가설 (한 문장)

> **<대상>** 이 **<상황>** 에서 **<행동>** 하면 **<결과>** 를 얻는다.

- 가설:
- 이 문장에서 가장 의심스러운 낱말: <보통 "얻는다" 예요>

## 2. 반증 신호 — 무엇을 보면 틀린 건가

| 신호 | 어디서 보나 | 이 값이면 틀린 것 |
|---|---|---|
| <예: 첫 사용 후 재방문> | <이벤트 로그> | <7일 내 재방문 20% 미만> |
| | | |

**작성 규율**: "잘 안 되면" 같은 표현 금지. **숫자와 기간**으로 적어요.
지금 숫자를 모르면 "모름 — 첫 측정 후 채움" 이라고 적고 넘어가요. 지어내지 않아요.

## 3. 위험 가정 순위

가설이 서려면 참이어야 하는 것들을 **위험한 순서로** 줄 세워요.
위험 = (틀릴 가능성) × (틀렸을 때 잃는 것).

| 순위 | 가정 | 왜 위험한가 | 가장 싼 검증 | 비용·기간 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

**규율 둘**

- **1순위부터 검증해요.** 만들기 쉬운 것부터가 아니라 틀리면 제일 아픈 것부터
- **가장 싼 검증은 대개 코드가 아니에요** — 사람 10명에게 보여주기, 손으로 결과 만들어 주기,
  랜딩 하나 띄우고 클릭 세기. "만들어 봐야 안다" 는 대개 검증을 미루는 말이에요

## 이 문서가 없으면

- "왜 이걸 만들죠?" 에 매번 다른 답이 나와요. 특히 병렬 세션은 각자 다른 가설로 만들어요
