# 성공·중단 기준

> 계속할 이유만 적고 접을 이유를 안 적으면, 접어야 할 때 **기능을 더 붙이게** 돼요.
> 두 기준을 같은 날 같이 정해요. 나중에 정하면 그때의 감정이 기준이 됩니다.

## 1. 계속 기준 — 무엇을 보면 다음 라운드로 가나

숫자 **3개 이하**. 많으면 아무것도 판정 못 해요.

| 기준 | 어떻게 재나 | 언제 | 통과선 |
|---|---|---|---|
| | | | |

**작성 규율**

- **"어떻게 재나" 를 못 적으면 기준이 아니에요.** 재는 방법이 손으로 세기여도 괜찮아요
- 첫날엔 대부분 "관측 가능한 사건" 이면 충분해요 (예: 10명이 끝까지 완주)
- 지금 통과선을 모르면 "첫 측정 후 정함" 이라고 적고, **첫 측정 날짜를 같이 적어요**

## 2. 중단 기준 — 무엇을 보면 접거나 방향을 바꾸나

| 기준 | 값 | 그러면 무엇을 하나 |
|---|---|---|
| <예: 4주 동안 재방문 5% 미만> | | <피벗 / 중단 / 대상 변경> |
| <예: 건당 원가가 감당 총액 초과> | | |
| <예: 파운더가 매주 N시간을 못 냄> | | |

**중단 기준에 시간·돈·의지를 다 넣어요.** 셋 중 하나가 먼저 바닥나요.

## 이 문서가 없으면

- 지표가 나빠도 나쁜 줄 몰라요. 기준선이 없어서요
- "조금만 더" 가 무한히 반복돼요 — 중단 기준은 미래의 나를 위한 장치예요
